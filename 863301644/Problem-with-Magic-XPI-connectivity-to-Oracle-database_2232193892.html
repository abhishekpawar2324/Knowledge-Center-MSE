Magic Global Support : Problem with Magic XPI connectivity to Oracle database

Created by Amjad Madre on 31,May, 2023

The customer gets an error message of Flow called Error flow, because of an error occurred Error ID 9805 not connected to ORACLE followed by a series of errors.

Error:

23, 206, 454, 350, 454,350,350, and then the flow hangs not sending anything back to the receiving application.

Below is the select statement:

Select ABAT1 from %env_Milacron_lib%F0101 Where aban8=<?C.HP_shipToNo?>

The error happens more frequently the longer the flow has been up without a restart.

After around 5-8 hours it is happening 30-50% of the time.

When submitting a change notice on an existing order, with a valid ship/sold number, it hangs on the pending screen.

If the error is the application and resubmits it will sometimes go through.

If restart the flow it goes through most of the time.

Solution:

  • Solved the issue by setting an oracle database timeout.

  • Not a magic XPI error other than a loss of connection.
