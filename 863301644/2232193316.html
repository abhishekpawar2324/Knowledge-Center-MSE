Scenario: Email: Unreadable data getting received while sending the mail

Following is the scenario:
Step 1) Read data from database and store it in blob variable using Data mapper.
Step 2) Send the email by including that blob in body and body type as HTML.
Output: Garbage Value in the Email getting Displayed

Solution: Using file management component changing the file charset.

Also The issue lies within the data itself with NULL terminator character in between the data.
After updating a blob with BlobAddBOM (UTF8fromUnicode (Blob),1) function with Binary encoding in flow data helps to resolve the problem.
