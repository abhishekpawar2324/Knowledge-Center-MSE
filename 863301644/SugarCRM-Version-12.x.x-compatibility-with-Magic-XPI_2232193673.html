Magic Global Support : SugarCRM Version 12.x.x compatibility with Magic XPI

Created by Amjad Madre on 31,May, 2023

The v11_16 rest version for SugarCRM release version 12.0.x. Which can be accessed from the browser on SugarCRM release version 12.0.x. like e.g https://<serverURL>/rest/v11_16/help

  • Our SugarCRM resource is configured with v11.3 and it works as expected with Rest api version v11_15.
    https://magicsoft.sugaropencloud.eu/rest/v11_15/help

    https://magicsoft.sugaropencloud.eu/rest/v11_15/help result from browser.

  • We can perform a call with help(https://magicsoft.sugaropencloud.eu/rest/v11_16/help) rest API to confirm if the URL connection working with v12 CRM or not.

  • The list of SugarCRM REST versions is supported with the released SugarCRM.

  • We don't have to change anything other than the URL - Rest api version i.e v11_16,
