Magic Global Support : How To Insert records into SQL tables from XML with Nested one-to-many Relationships in XPI

Created by Amjad Madre on 31,May, 2023

The customer had a query about inserting a record from an XML where we have one-to-many at 4 levels in the XML file.

 For Example- a shipment XML file that has orders as children. and 1 order can have multiple containers and 1 container can have multiple items. When reading such an xml file, we need first to insert the shipment in shipments table, grab the id of the shipment and then drop it down to orders. For each one of the orders attached to the parent shipment, we need to insert the order, grab the id of the order and drop it down to the packages, and so on.

So to get this thing done we have first created tables (e.g. Shipment, Order Container, items). As per the customer’s concern.

Here we have mentioned ShipmentNo from “Shipment” table as a foreign key in all the other tables and also  containerId from “container” table as a foreign key with “Item” table to provide a Nested relationship between the Data tables in the respective format.

So in XPI we can first read the xml file using File Management component and store the data in a blob variable.

And then inside Datamapper, We have mapped the XML Schema with call flow schema where we created a flow for each table respectively(Shipment, Order, Container, Item)

We have created a flow variable in each of the following flows according to the data fields which are being mapped from XML to call flow.

 

So, in each of the flows using a data mapper we have mapped the variable schema with the database in the destination to store the values in a Nested One-To-Many relationship.

Here in database, you can see under one LoadNo which is a ShipmentNo in item table is multiple item is getting stored.

So in this way, we can store the Data inside SQL with one-to-many relationships from the XML file.
