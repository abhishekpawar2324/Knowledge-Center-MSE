Magic Global Support : Webservice-Server SOAP 1.1 - Compliance-Error

Created by Vaishnavi Marathe on 05,Jan, 2024

There was a scenario where customers were migrating from XPI  4.7.9 to 4.13.4 and observed compliance errors when calling the new web services.

Webservice Provider: Consuming Webservice from XPI returns Schema Compliance -FAILED

The customer has generated a service with XPI WebS Provider.
Consuming the same service shows the below error in SOAP UI:

  • Schema Compliance -FAILED in SoapUI.

After investigation, the errors related to Schema Compliance come inside the SOAP UI and vary from response to response.
It was suspected that it can be a problem side of SOAP UI, and not from XPI wsdl.
