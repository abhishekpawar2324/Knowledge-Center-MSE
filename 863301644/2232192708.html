Magic Global Support : Handling HTTP Error 500.0 – Internal Server Error

Created by Amjad Madre on 31,May, 2023

When trying to execute a web application, this error occurs if the timeout exceeds while waiting for a response.

 There are several ways to solve this problem:

 First, under IIS follow the provided steps:

 

  • Open your IIS.

  • Go to "Sites" option.

  • Mouse right-click.

  • Then open property "Manage Web Site".

  • Then click on "Advance Settings".

  • Expand section "Connection Limits", here you can set your "connection time out"

By default, its 120 seconds (2 minutes)

Here you can set valid values between 0 to 300 (seconds)

So, make it 300 seconds i.e 5 minutes

Second approach increase the configured Timeout change the timeout from the

mgreq.ini <installation dir>\Runtime\Scripts\config>

 

By default, it is 30 sec you can increase it to 300 sec (i.e 5 min), after making changes in mgreq.ini make sure to restart the IIS.

 

Also check the IIS timeout is more than the timeout set in mgreq.ini attached screenshot for reference (by default IIS timeout is 1:50)

(** Please always restart IIS after making changes in IIS or mgreq.ini)
