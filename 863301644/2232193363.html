Magic Global Support : Email adapter: When the TLS connection is enabled, what are the details of the TLS version, Does it depend on the settings in the Windows registry? (for XPI 4.9)

Created by Amjad Madre on 31,May, 2023

Solution:

The TLS connection is based on the JAVA version. For the JRE 1.8,by default it connects to the TLS1.2
Because JRE 1.8 supports the TLS 1.2 only.

For the JRE 1.7,we need to enable the TLS 1.2 settings. So, it does not connect to the TLS 1.2 directly.

In the higher version of XPI i.e XPI 4.13,it only support the JRE 1.8 so ,it is by default connect to the TLS 1.2
