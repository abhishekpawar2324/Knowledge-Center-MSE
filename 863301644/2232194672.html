Magic Global Support : How to set SOAP service with load balance webservice URL ?

Created by Amjad Madre on 31,May, 2023

 

In order to use the load balance webservice URL we need to configure one file (i.e config.properties)

 

Path: XPI_installation/xpi_webserver/webservice-config/config.properties.

 

In the config.properties file, we need to change the hostname in the parameter ‘service.root.url’.

For example:-

service.root.url= http://localhost:6060/services to http://10.9.8.73:6060/services

Here, 10.9.8.73 is a machine IP.

 

Note:

After updating the config.properties file.
Please restart the SOAP service.
