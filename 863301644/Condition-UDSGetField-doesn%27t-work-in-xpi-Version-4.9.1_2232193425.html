Magic Global Support : Condition UDSGetField doesn't work in xpi Version 4.9.1

Created by Amjad Madre on 31,May, 2023

Problem Description :

Data Mapper ORDER_HEADER_IN Condition UDSGetField ('F.UDS_Lock', 'Key', 'Header', 'Lock', U.UDS_Lock) doesn't work in xpi version 4.9.1

 

Following instructions to change in project:

  • Remove the UDSUpdateField from the first simple element calculated value.

  • Add the UDSUpdateField to an element which is NOT required but only for the update evaluation. For example: BAPI_SALESORDER_CREATEFROMDAT2/Import/ORDER_HEADER_IN/EXCH_RATE_FI_V can be used for this.

  • For the above node add the calculated value with the UDSUpdateField.

  • The element itself WILL NOT BE SHOWN but the uds field will be updated as the last action for the processed first line.

  • When the engine will process the second line the requested behavior will take place and line will not be part of the result.
