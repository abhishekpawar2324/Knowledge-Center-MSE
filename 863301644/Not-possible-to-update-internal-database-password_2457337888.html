Magic Global Support : Not possible to update internal database password

Created by Vinayak Dane on 23,Feb, 2024

Customer Issue: There is problem that it is not possible to update internal database password,
If you try to change the password for the internal database you'll get a success message in logs, but the password is not changed.

 

Affected version:4.13.6

 

Steps for reproduction

  • -Install 4.13.6

-Run MagicxpiDBSecurity.bat using cmd(administrator)
-update the required password, Enter Your New Password: Magic@123456 (any password you wish),you can observe logs will be generated with information as
********************************************
MAGIC_XPI_HOME = D:\Magic\XPI\413
JAVA_PATH = D:\Magic\XPI\413\Runtime\JDK8x64
********************************************
Executing the Encryption mechanism in auto mode.
The password has been modified.
Password Encryption process completed, see the database connection attributes file for result.
********************************************

-now try to connect internal database with new details-it fails
but if you use default password MagicPass#3 it connects.

 

On further investigation we understand this issue cannot be fixed as this utility is used for updating the new password only in datasource.xml in Runtime\Config folder. It is not used for updating the password in the database. Updating the password of the internal database is user’s responsibility.
