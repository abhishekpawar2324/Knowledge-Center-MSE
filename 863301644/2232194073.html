Magic Global Support : Use of Collection column of OData Service’s Entity Properties.

Created by Amjad Madre on 31,May, 2023

OData’s Collection of properties is an Odata Specification, and it means it is an array of values,

The collection column inside properties of Odata's entities is used to define a set/collection of the same property.

To access the collection column, go to the OData Service and click on the Entities button.

Then click the zoom button from the Properties column.

You will find the collection column from which we can check or uncheck the property. Checked means there can be more than one value of that specific property.

We can perform the GET operation on the specified OData with the collection column checked, below is the result from an XML file with multiple Email addresses, which we defied by checking the collection checkbox of OData’s properties.
