Magic Global Support : Resolving "Waiting for Agent" Status in Monitor

Created by Abhishek Pawar on 07,May, 2025

Issue

When attempting to run a project from the Monitor, the Server tab displays the status:
"Waiting for Agent".

Cause

This typically occurs when the IMM agent is either not properly registered, unavailable, or the project is not correctly mapped to a server instance.

Resolution Steps

  1. Open Monitor Dashboard

  • Navigate to the Dashboard tab in the Monitor.

  • Check if the IMM Agent status is listed as Available.


  1. Copy Agent Name

  • If available, copy the Agent Name exactly as it appears.

  1. Go to Server Tab

  • Switch to the Server tab in the Monitor interface.

  • Open or create a Server Instance configuration.

  1. Add Server Host and Project Directory

  • In the Server Host field, paste the Agent Name (e.g., in-abhishekplpt).

  • In the Projects Directory, input the correct project path.

  1. Verify Settings

  • Ensure the following checkboxes are selected:


  ✅ Load Triggers
  ✅ Load Schedulers
  ✅ Load Auto-Start

  1. Save and Run

  • Click OK to save the new Server Instance.

  • The project should now start running under the correct agent without showing “Waiting for Agent”.
