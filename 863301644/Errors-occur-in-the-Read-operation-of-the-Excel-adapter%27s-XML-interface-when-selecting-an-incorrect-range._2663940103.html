Magic Global Support : Errors occur in the Read operation of the Excel adapter's XML interface when selecting an incorrect range.

Created by Vaishnavi Marathe on 10,Jun, 2024

There was a scenario where a customer encountered errors while reading data from Excel using the Excel connector in XPI.

 

After executing the project, the following error was observed:

'Error 1801: error in transformation process .error in Read operatin.com.magicsoftware.xpi.sdk.SDKException: error in read file operatin due to {} java.lang.IndexOutOfBoundsException: Index: 0, Size: 0'

 

 

After investigation we observed that this error occurs when there are no records in the rows and an incorrect range is specified.
When we define the range according to the records to be retrieved, it works and returns the right data without any errors.

 

Additionally, users can select the workbook file and range using the wizard.

If the range is not selected and there is no data during the read operation, the aforementioned error occurs.

The customer reported this issue in XPI 4.14, and it has been fixed in XPI 4.14.1.

For Reference:

MXPI-31753 - Excel: Read operation of Excel Adapter's XML Interface returns an error if the specified range contains blank records. Closed
