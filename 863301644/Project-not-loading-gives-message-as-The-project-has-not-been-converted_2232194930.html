Magic Global Support : Project not loading gives message as The project has not been converted

Created by Amjad Madre on 31,May, 2023

The customer installed XPI 4.13.5 on Windows Server 2012.

Created a new project and then save it.

Close the project and try to load it, the customer was getting an error that the project cannot load: 'The Project has not been converted'.

**To overcome this scenario below steps are followed and resolved the problem.

This error is usually observed when Visual Studio 2010/2015 Isolated Shell is missing or has got corrupted due to unknown reasons.

This needs to be re-installed only if this is observed due to corruption/missing shell.

or

Verify that .NET Framework 4.0+ is installed on your machine.

You can verify this in 'Control Panel\Programs\Programs and Features'.

Download the isolated shell 2015.

Download the file and go to the properties of the file and unblock it if you see unblock checkbox in properties.

Then extract the zip and install the "vs_isoshell.exe".

Note:

Please stop the projects and close the XPI studio before installing the isolated shell.
