Magic Global Support : The server terminates abnormally at a specific step

Created by Vaishnavi Marathe on 04,Mar, 2024

We had a scenario where the customer was facing server abnormal termination abnormally on the data mapper step with the Oracle database.

Reproduction was not possible at the support end.

We asked for projects,  logs, and procdumps (With Gflag ON & OFF).

 

We have a RDC: MXPI-30690 - XPI engine terminated abnormally happen for specific datamapper step. Closed

The RCA of the issue is as follows:

RCA for the problem of invalid column name definition on the source DB schema of the specified step (Step 1_22_5).
The Wong definition is likely to have happened due to UI's wrong behavior that finalized the definition of the column to be invalid

The next images present the wrong column definition and as a result, the Generated code suffers from the wrong XPA variable definition.

·        It is true that the column is not connected but once it is selected xpa DSQL will try to insert a value into that column and the XPA program will crash.

 

·        The XPI properties for a non-connected column cannot be changed from their default which are StringDate=No and AlwaysUseCustomerPicture=No. There were cases in previous versions that due to manipulations of connection removal these properties remained in an invalid state like here. The UI affects the generated code and since Alpha cannot receive values except digits the XPA size is zero.

In the recreated step the above column has the valid XPA picture and the data type is Date and not Alpha - check the next similar images for the recreated step.

Ansare to the customer’s query whether recreating the step is the correct action - Yes for sure.

 

·        The old step can also be corrected by simply connecting this column and setting the string date and AlwaysUseCustomPicture to false - and then removing the connection OR remove that column from the SQL statement so that it will no longer be part of the XPA-generated code data view.

 

This solved the issue at the customer’s end.
