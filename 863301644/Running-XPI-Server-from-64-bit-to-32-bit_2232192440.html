Magic Global Support : Running XPI Server from 64-bit to 32-bit

Created by Amjad Madre on 31,May, 2023

Running XPI server from 64-bit to 32-bit vice-versa
The Magic XPI server now natively run as a 64-bit process providing better performance and larger memory capacity.
Apart the studio is still running under 32-bit version.
Under <Installation directory>\Runtime it contains two sub folders called 'Magic xpa' (32-bit) & 'Magic xpa x64' (64-bit) contain the relevant dlls.
So to debug your engine under 32-bit version you need to apply following changes:

  • Under ...\Runtime\Gigaspaces-xpi\config\gsa\mgxpi.xml location

    Remove the x64 so that it reads as follows:
  • windows="${com.gs.home}..\Magic xpa\MgxpiServer.EXE" unix="MAGIC_XPI_HOME_DIR/bin/mgxpiserver">



After applying the changes restart the server.
