Magic Global Support : Rest Client: The header parameter values set in configuration do not reflect in resource settings

Created by Vaishnavi Marathe on 21,Jun, 2023

We had the following Customer Query:

 The header parameters and key values in RestClient Component configuration management do not change or are not in sync with the setting-resources-rest client paths button key values."

 

According to the query:

The user can change the default value of one or more parameters in the list of header parameters in the Rest Client Component configuration manager.

 

The user can either enter the new value directly or click to open the REST Client Configuration - Value window to change the value.

Only static header parameters can be defined in resource settings.

Where the values will never change after they have been defined for the first time.

Changes to the defined values can be made in the rest client component configuration manager (parameters).

 

Reference Bug:  #MXPI-25764 - Rest Client: The header parameter values set in configuration does not reflect in resource settings.

It was observed from XPI version 4.9.

According to Product Management, this behavior is considered as normal and no changes are required, hence, the bug got rejected.
