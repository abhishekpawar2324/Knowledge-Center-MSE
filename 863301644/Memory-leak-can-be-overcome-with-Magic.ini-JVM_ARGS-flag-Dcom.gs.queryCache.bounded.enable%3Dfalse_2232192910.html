Magic Global Support : Memory leak can be overcome with Magic.ini JVM_ARGS flag Dcom.gs.queryCache.bounded.enable=false

Created by Amjad Madre on 31,May, 2023

In XPI, There was memory leak issue is confirmed from R&D and handled after adding flag in magic.ini(this is part of hotfix 4.7.9)

Please use the Magic.ini flag -Dcom.gs.queryCache.bounded.enable=false in JVM_ARGS section.

Please make the changes in Magic xpa/Magic.ini and Magic xpa x64/Magic.ini file into the JVM_ARGS= section.
Flag: -Dcom.gs.queryCache.bounded.enable=false
