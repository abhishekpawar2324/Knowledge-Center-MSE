Magic Global Support : Simple Recovery Model to Shrink database size

Created by Amjad Madre on 31,May, 2023

If we go into the XPI database,

unnecessary space is used when having the database recovery model is full.
In the background, it generates a database size huge.

XPI Database in datasource.xml-

When you go to MS SQL Server Management you can see the size of the XPI Database.

Now Using the simple recovery model keeps less database size and increases the performance somewhat.

USE MGXPI413

EXEC sp_helpdb @dbname= 'MGXPI413'

ALTER DATABASE MGXPI413 SET RECOVERY Simple

DBCC SHRINKFILE (MGXPI413_log , 1)

After performing the simple recovery model make sure to set the Database FileType - Rows Data and LOG to Unlimited of its Maximum File Size.

After applying the Simple Recovery Model We get the result of Database size as follows-

So according to the internal database name, we can write down the query or create a template.
