Magic Global Support : Configuration of Magic Monitor and XPI server on different machines:

Created by Amjad Madre on 31,May, 2023


The document explains, how to configure the magic monitor and XPI server on the different machines only by running the magic monitor service.
The magic monitor and the XPI servers both are installed on the two different machines.
We can see the running projects on the Magic Monitor server only by running the Magic monitor service.

Steps to Configure the two servers:
1-Install the Magic Monitor on the server1






2- Change the value of the Lookup locator name and lookup Group name by the value of the server(Magic GSA server lookup locator)













3-Untick the Run script option and go forward with the installation.

4-Copy the datasource.xml file of the Magic GSA server on to the Monitor server(where the magic monitor is installed).
%InstalltionDir4.9%\Runtime\Config\datasource.xml
5-Copy the Options.ini file of the Magic GSA server on to the Monitor server.
%InstalltionDir4.9%\Runtime\RTView\magicmonitor\OPTIONS.ini
6-Confirm the runwebmonitor.bat of the Monitor server
(C:\Magic xpi4.9\Runtime\RTView\magicmonitor\runwebmonitor.bat)
-if not then Change the set LookupGroupName=Server2(Magic_xpi_4.9_ITSWIN7)
set LookupLocators=Server2(ITSWIN7)
7-Start the only the magicmonitor service through the task manager of the Monitor server
8-Start the GSA service of the Magic GSA server.
9-For the projects, the path of the projects must be same on the both the servers.- You can keep the same copy of the projects on both servers.Change the Folderpath Accordingly on the both servers(Monitor server and Magic GSA server). Result: you can use this **(This is not tested by QA this findings are from Support)Please test this configuration on UAT/DEV env. before using in the production.
