Magic Global Support : IF_4.13.4:Debug logs writing in the stdout.log file.

Created by Abhishek Pawar on 16,Dec, 2024

The customer reported an issue with the presence of stdout.log and stderr.log files along with their backup (.bck) files within the "Runtime\logs\java" folder.

These files were generated in large sizes in a customer environment.

Customer using Magic xpi 4.13.4 and the attached isolated fix provided on the bug: MXPI-30230: Isolated fix - Error "8888: .Net Exception" occurs in add-on connector "SQLCommander" created by connector builderClosed

The debug log is enabled, and logs are written in stdout.log.

We identify that the xpiserver_${pid}.log file is not generated when using the 00096512 isolated fix.

 

Support observation:
Ideally, it should log the information in (xpiserver_${pid}.log).
In the customer logs, we did not see this file is created.
