TCPListener: The timeout setting of the TCPListener trigger looks like hardcoded for 30sec

There is a timeout setting on the service setting screen of the TCPListerner trigger.

The default is zero and there is no timeout.

However, it actually times out in about 30 seconds.

The timeout value of 0 will not be considered infinite for the TCP Listener component. For a higher timeout, specific a greater value as per requirement. This applies to <Magic xpi installation>\\Runtime
