Magic Global Support : Magic Monitor 4.13 (RTView) does not start when installation having a long directory path

Created by Amjad Madre on 31,May, 2023

The customer was facing "Error: Cannot connect to display server".

When the Magic XPI monitor started manually using the runwebmonitor.bat file using the command line.

The error: The syntax of the command is incorrect observed in the command line.

To generate the log file, you will have to add Echo and log file to capture the logs in the run_launcher.bat file,

which is present at the location: <installation folder>\Runtime\RTView\bin\run_launcher.bat

To generate the log file, you will have to add Echo and log file to capture the logs in the run_launcher.bat file, which is present at the location: <installation folder>\Runtime\RTView\bin\run_launcher.bat

Please make changes as follows:

ECHO "%JAVAEXEC%" -DRTV_HOME="%HOMEDIR% " -DRTVOC_HOME="%RTVOC_HOME% " -DHAWK_ROOT="%HAWK_ROOT% " -DCOHERENCE_HOME="%COHERENCE_HOME% " -DRV_ROOT="%RV_ROOT% " -DTIBJMS_ROOT="%TIBJMS_ROOT% " -DSB_CP="%SB_CP% " -DRTV_USERPATH="%RTV_USERPATH% " -DRTV_JDBCPATH="%RTV_JDBCPATH% " -DRTV_DEMOSERVER="%RTV_DEMOSERVER% " -DRTV_JAVAOPTS="%RTV_JAVAOPTS% " -DJAVA_HOME="%JAVA_HOME% " -cp ./myclasses.jar;./gmsjlauncher.jar;./gmsjrtvquery.jar;"%HOMEDIR%/lib/gmsjlauncher.jar";"%HOMEDIR%/lib/gmsjrtvquery.jar";"%RTV_USERPATH%" com.sl.gmsjlauncher.GmsLauncher %OCMCONN% > ..\bin\run_laucher_Command.log

ECHO %* %OCMCONN% >> ..\bin\run_laucher_Command.log

This is a kind of issue related to the length of the PATH supported, as on windows it’s limited to 260 max.

This error is thrown when the installation path is big where it has a longer directory name.

To resolve this:

Simply add the following lines in the runwebmonitor.bat file, after the ROOT_LONG_NAME line.

set ROOT_LONG_NAME=d:\mse\Magic\xpi\4.13\product\xpi\Magic xpi 4.13

mklink /J C:\MagicXPIPath "%ROOT_LONG_NAME%"

set ROOT_LONG_NAME=C:\MagicXPIPath
