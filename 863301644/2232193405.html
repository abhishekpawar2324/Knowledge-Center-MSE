Magic Global Support : SugarCRM: REST endpoint is incorrect

Created by Amjad Madre on 31,May, 2023

Problem Description :

Not able to validate the SugarCRM resource. (XPI 4.9)

For example https://dungstest.sugaropencloud.eu/rest/v10/

If click on the "validate" button in the resource, get an error "REST endpoint is incorrect".

 

Solution:

Need to upgrade the JRE version to 8 which is in use in your configuration.

If the error shows in the validation. This might be due to the TLS version.

  • "Support for TLS versions 1.1 and older in SugarCloud will be disabled on February 1, 2020. THIS IS A FIRM DEADLINE AND WILL NOT BE EXTENDED"

  • "We need to upgrade the JRE version 1.7 or 1.8 which enables the TLS1.2 by default"
