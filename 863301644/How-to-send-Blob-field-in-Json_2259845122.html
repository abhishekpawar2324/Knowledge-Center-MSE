Magic Global Support : How to send Blob field in Json

Created by Shubham Kulkarni on 11,Jul, 2023

Problem:

We could not send Bolb data when the data size is more than 1000.

Solution:
Please set the rarely used datatype in JSON structure and then overwrite that datatype in magic.

E.g.

We are using the boolean type in JSON Schema and in magic it will treat the Boolean type as a blob
