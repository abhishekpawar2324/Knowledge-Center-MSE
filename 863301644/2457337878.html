Magic Global Support : DB Password is not changed if last character of the new password is "^"

Created by Vinayak Dane on 23,Feb, 2024

Customer Issue: There is a problem when DB Password in datasources.xml is not changed if last character of the new password is "^"

 

Affected version:4.13.6

 

Steps for reproduction
-Install 4.13.6
-Run MagicxpiDBSecurity.bat using cmd(administrator)
-update the required password,Enter Your New Password: Magic@123456^ (any password you wish),you can observe logs will be generated with information as
********************************************
MAGIC_XPI_HOME = D:\Magic\XPI\413
JAVA_PATH = D:\Magic\XPI\413\Runtime\JDK8x64
********************************************
Executing the Encryption mechanism in auto mode.
Password has been modified.
Password Encryption process completed,see the database connection attributes file for the result.
********************************************

However, if we check the datasources.xml the encrypted password remains the same "RA/jnTXRDi3+i3JOm6ph1w=="

 

 

On further investigating we understand this issue cannot be fixed due to architecture limitation,

As we are not using DB security in new infrastructure of xpi 4.14.

This bug is limited to Gigaspaces infrastructure,moving to xpi 4.14 this is no more applicable
