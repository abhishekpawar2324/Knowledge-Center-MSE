Magic Global Support : Scheduler Service: The scheduler service is ignored if more than 231 entries are created in Time(s) to Execute of Scheduler.

Created by Amjad Madre on 31,May, 2023

One of the customers reported the following issue with the Scheduler utility.

Suppose more than 231 entries are created for the execution time of the Schedular service. In that case, nothing will be displayed on the scheduler tab of Magic Monitor, and the schedular service gets ignored. See the below image,

If the number of entries for execution time is small, then there is no problem. See the below image,

For this issue, we have a bug reported in which an isolated fix is provided on top of XPI 4.13.2, 4.13.3 and 4.13.4

( MXPI-25749 - Isolated fix - Scheduler Service: The scheduler service is ignored if more than 231 entries are created in Time(s) to Execute of Scheduler. Closed )

After applying the isolated fix, we can see both the schedulers (Scheduler_1 from flow1 and Scheduler_2 from flow2) are listed inside the scheduler tab of the magic monitor display.
