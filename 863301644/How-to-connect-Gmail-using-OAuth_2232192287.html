** Following steps to configure resource in xpi for OAuth 2

  1. After Selecting authentication type as OAuth 2 , it will shown different parameter as following  image

 

Authorization URL and Access  Token URL are constant values for every project

Authorization URL : https://accounts.google.com/o/oauth2/v2/auth

Access  Token URL  : https://oauth2.googleapis.com/token

Call back URL : ( give url which is given while creating app )

Client Id :  ( Use copied client id or download .json and use client id which is shown in json file)

Client  Secrete : :  ( Use copied client secrete or download .json and use client secrete which is shown in json file)

Scope :  Which you want to access app

Eg : https://mail.google.com

State : (Not a mandatory parameter )

Eg : magic
