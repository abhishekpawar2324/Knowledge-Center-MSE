Magic Global Support : File Splitting Issue with Bulk Retrieve Query Results in Salesforce Connector

Created by Balaji Karagir on 02,Jan, 2025

Problem:

Customers have reported that when using the Bulk Retrieve Query Results method in Salesforce, the output is sometimes divided into 3 CSV files and sometimes into 2 CSV files, even though the output file size appears to be the same.

Version Affected:

  • Magic XPI Version 4.1 and above

Cause:

This behavior is due to the Salesforce Bulk Query API, which Magic XPI uses to fetch data from Salesforce. The splitting of files into multiple CSVs is managed entirely by Salesforce's API. The number of files is not under our control, and the exact logic behind this split is not publicly documented by Salesforce.

Update from Product Management:

According to product management, Salesforce itself handles the logic for splitting the data into multiple CSV files. Magic XPI does not have any direct control over this splitting process, and this behavior can vary depending on factors such as:

  • Size of the data being queried

  • Salesforce API handling for large datasets

Possible Solution:

Since the issue is related to how Salesforce handles file splitting internally, there is no direct solution to control or change how Salesforce splits the data into CSV files. However, there are some steps you can take to manage or automate the handling of these files after they have been generated:

  1. Automate file merging: Once the CSV files are retrieved, you can set up a process to automatically merge the files into a single one if needed.

  1. Salesforce Documentation


For more information on how Salesforce handles large datasets and the Bulk Query API, refer to Salesforce’s official documentation on bulk API limitations and data handling.

Additional Considerations:

  • File Splitting Logic: The number of files generated is not necessarily proportional to the file size; Salesforce may split files based on internal factors that are not exposed to the users or integrators. Therefore, the size of the output files does not always correlate with the number of files returned.

· The number of CSV files created can vary from 1 to 15, depending on the size of the data being returned. Salesforce splits the data into multiple files if the output exceeds 1 GB, but it may still produce multiple files for smaller datasets depending on the API's internal logic.

· Salesforce API Limitations: There is a cap of 15 CSV files per query, with each file having a maximum size of 1 GB.

 

At this time, there is no change expected from Magic XPI to address the file splitting, as this behavior is driven by the Salesforce Bulk Query API. However, we recommend reviewing Salesforce documentation for any updates on their handling of bulk queries and CSV outputs.
