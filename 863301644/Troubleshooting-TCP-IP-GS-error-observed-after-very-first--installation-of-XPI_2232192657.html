Magic Global Support : Troubleshooting TCP-IP GS error observed after very first installation of XPI

Created by Amjad Madre on 31,May, 2023

This is a commonly observed error which is usually observed when we start GSA services for the first time on a fresh installation

ERROR [org.hibernate.engine.jdbc.spi.SqlExceptionHelper] - Cannot create PoolableConnectionFactory (The TCP/IP connection to the host ITSW10VM4, port 1433 has failed.

Error: "Connection refused: connect. Verify the connection properties. Make sure that an instance of SQL Server is running on the host and accepting TCP/IP connections at the port. Make sure that TCP connections to the port are not blocked by a firewall.".)

 

This leads to mginfo-gs broken

 

To resolve this error we need to make sure the TCP properties of SQL server is enabled on internal Database server and XPI server machine both.

You can enable this as follow

1.Open SQL configuration manager / MMC

2.Select SQL server network configuration and enable protocols for the instance used as internal XPI database server

 

 

3.Select SQL Native client Configuration 32-bit and enable TCP protocols

 

 

4.After enabling TCP protocols on server and client make sure to restart SQL server services for changes to effect.

 

 

5.Restart XPI GSA services and check if the problem is resolved

 

6. In case the problem is not resolved verify for client and server TCP/IP properties do not point any IPv6 addresses ,if is change the IP to 127.0.0.1

 

 

Also make all ports of TCP/IP to 1433

 

 

7.Restart GSA and SQL server services for changes to effect and check again
