Magic Global Support : Data Mapper shows the difference in output when the project is upgraded to 4.9.1

Created by Amjad Madre on 31,May, 2023

Problem Description :

Data Mapper shows the difference in output when the project is upgraded from 4.5a to 4.9.1.

The project is version 4.5a. Works fine in 4.9. Also happens for 4.9.2 and 4.12.1 also. The append data is used in the data mapper.

 

Need to do the changes in the project:

The solution for the customer is to have the XSD XSD\SAP_SALESORDER_RESULT_v2.xsd (if possible) changed to having the root element 'SAP_SALESORDER_RESULT' (for this example project ) as multi occurrences - This way the process will aggregate the root for as many iterations of the source which exist. 

For reference:

Home > Reference Guide > Utilities > Data Mapper Utility > Source and Destination Properties Panes > XML Properties > Append Data Rules
