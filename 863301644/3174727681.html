Magic Global Support : Troubleshooting a Forgotten Database Password: By Creating a New User with User Mapping in MSSQL

Created by Pooja Thakkhi on 28,Jan, 2025

Scenario: The customer has migrated their MSSQL server to a new MSSQL server. They created a database user and password, but the user forgot the new password.
To troubleshoot this scenario we created a new user and assigned access and database rules using user mapping.

 

Steps to Create a New User and Configure User Mapping:

 

Step 1: Open SQL Server Management Studio (SSMS)

  1. Launch SSMS and connect to the MSSQL Server using an account with administrative privileges.

Step 2: Navigate to Security Settings

  1. In the Object Explorer, expand the server node.

  2. Expand the Security folder.

  3. Right-click on Logins and select New Login...

Step 3: Create a New Login

  1. In the Login - New window:

    • Enter a Login Name (e.g., NewDBUser).

    • Select SQL Server Authentication and enter a new password.

    • Confirm the password.

    • Uncheck Enforce password expiration (optional, based on security requirements).

  2. Click OK to create the login.

Step 4: Configure User Mapping

  1. In the Object Explorer, right-click the newly created login under Logins and select Properties.

  1. In the Login Properties window, select the User Mapping tab.

  2. Under Users mapped to this login:

    • Check the box next to the desired database (e.g. Test)

    • In the Database Role Membership for: Test, assign roles such as:

·         db_owner for full administrative rights.

·         db_datareader for read access.

·         db_datawriter for write access.

  1. Click OK to save the settings.

  2. Refresh the Database.

  3. Right-click on the database (e.g., Test) and select Properties.

  4. Navigate to the Permissions tab to verify the newly created user (NewDBUser) and the assigned permissions.

  5. Click OK to save the settings.

Step 5: Test the New User

  1. Disconnect the current session in SSMS.

  2. Reconnect using the newly created login credentials.

  1. The user can access the required database and perform the assigned operations.

  1. The user cannot access databases where permissions were not granted.

Conclusion: By following these steps, you can resolve issues caused by forgotten passwords by creating a new user and assigning appropriate access using user mapping in MSSQL Server.
