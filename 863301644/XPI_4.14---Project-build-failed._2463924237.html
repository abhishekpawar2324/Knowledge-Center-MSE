Magic Global Support : XPI_4.14 - Project build failed.

Created by Shweta Salunkhe on 28,Feb, 2024

Description:

The customer is trying to build the project(New or old) in XPI 4.14 and observes build failed with the error in the studio logs.
-Mgxpi.Log {ERROR} - Error occurred! Project ibp wasn't created
-Mgxpi.Log {INFO} - Build finished with result: Failed

The problem is specific to a particular machine.

Solution:

We had the customer session and we found out that after removing the environment variable _JAVA_OPTIONS the project build works perfectly.
