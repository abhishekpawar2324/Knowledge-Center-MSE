Magic Global Support : How to use a REST Client with Google API for Spreadsheet

Created by Pooja Thakkhi on 12,Sep, 2024

  • Why Rest Client is used?

A REST client is a tool that helps communicate with RESTful APIs by sending requests and getting responses. REST is a common method used to design web services because it's simple, flexible, and efficient for building network applications.

  •   Steps to Validate Rest API Client :

  1. Link to the Google API Console.

  • Open the Google API Console. This is where all the Google Cloud projects and APIs are managed.

  1. Create a New Project

  • In the Google Cloud Console, create a new project by clicking on the project dropdown and selecting New Project.

  • This will allow you to manage different APIs and credentials for each individual project.

  1. Select the Project

  • After creating the project, manually select it from the project Notification menu.

  • This step ensures that all the APIs and credentials you enable or create are associated with the current project

  1. Navigate to APIs and Services

  • In the Google Cloud Console, click on the navigation menu (the three-line hamburger menu) and go to APIs & Services.

  • Select Enabled APIs & Services to manage the APIs enabled for your project.

  1. Enable Google Sheets and Google Drive APIs

  •   In the API Library, use the search bar to find the Google Sheets API.

  • Click the API and select Enable. Repeat this step for Google Drive API.

  Google Sheets API: Allows interaction with Google Sheets (read/write access).

Google Drive API: Manages access and sharing permissions for files (including Google Sheets).

  1. Go to the navigation menu, select Credentials, and create an API key under the Credentials section

  1. Created an API key

  1. Configure OAuth Consent Screen

  • Return to the Create Credentials section and generate an OAuth Client ID

  • Navigate to the Configure Consent Screen.

  1. Click on External and Create

  1. Enter the required details:

  • App Name: A name that users will see when granting permissions.

  • User Support Email: Your contact email.

  • Developer Contact Information: For notifications and user inquiries.

  1. Click on Save and Continue

  1. Add the Test Users

  • After saving the OAuth consent details, add Test Users:

  • Enter your email and the emails of others who will test the app.

  • Test users are the only ones who can authorize the app in its unverified state.

  1. Add your email address and save and continue

  1. In summary, all the information that has been provided will be displayed, and you can then click on Back to Dashboard.

  1. Create OAuth Client ID

  • Go to the Credentials section, select Create Credentials, and then choose OAuth Client ID.

  • Select Application type as Web Application and give Name

  1. Add Authorized redirect URIs and Create

  • Redirect URIs are required for OAuth to know where to redirect users after authorization

  1. After Creating the Redirect Download OAuth Credentials JSON File

  • After creating the OAuth Client ID, download the JSON file.

  • This JSON file contains your Client ID, Client Secret, and other important details for OAuth 2.0.

  1. Create Service Account

  • In the Credentials section, click Create Credentials → Service Account.

  • Enter a Service Account Name

  • Click Create and Continue.

  • A service account allows your application to act on behalf of users, without requiring user interaction each time.

  • After creating the service account, note down the Service Account Email.

  • This email will be used to share the Google Sheet, granting programmatic access to the service account.

  1. Click Done once the service account is created.

  1. All the credentials have been successfully created and are now visible.

  1. Open the Command Prompt (CMD) and execute the JSON file.

  1. It will redirect to Visual Studio Code, where the credentials within the JSON file will be visible.

  1. Create Google Spreadsheet

  • Open Google Sheets and create a new spreadsheet.

  • The sheet will be used to read/write data via the Google Sheets API.

  1. Share the Spreadsheet with the Service Account

  1. Click on the Share button

  • Click the Share button in Google Sheets.

  • Enter the Service Account Email and give Editor permissions.

  • Click Send. This allows the service account to read/write to the sheet.

  1. Open the XPI studio 414

  • Create a new Project

  • Go to the resources and Add resource as Rest Client and click OK

  • Paste the URL and select the Security as OAuth2

               https://sheets.googleapis.com/v4/spreadsheets

  • Copy the Authorization URL, Access Token URL, Callback URL, Client ID, Client Secret

  • Code from VS to XPI

  1. Click on the Access Token, and a page or prompt of this type will appear.

  1. After signing in with Google, select the account associated with the Google API Console.

  1. After selecting a Gmail account, click Continue as shown below.

  1. If this page is displayed, the access token has been successfully verified.

  1. Return to the XPI Studio and verify that the access token has been successfully generated.
