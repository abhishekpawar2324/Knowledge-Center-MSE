Magic Global Support : Error Loading Java Classes in Studio

Created by Amjad Madre on 31,May, 2023

Connector: JAVA Class connector

 

Objective:

      When clicking on Configuration with the Java Class connector, then clicking on the dropdown for Class Name (three dots), and the error appears “Error in the application”.

 

 

·         This error is fixed in XPI 4.13.1.

 

Workaround:

But we have provided the below workaround to the customer to work with XPI 4.13

             We can use Java components in XPI 4.13 by applying the below workaround:

             You can remove or comment the ‘CLASSPATH=’ section in the magicxpi_studio.ini

             %Xpi installation%\Runtime\Magic xpa\magicxpi_studio.ini
