Magic Global Support : How to get the date-time string in UTC datetime format?

Created by Amjad Madre on 31,May, 2023

If you want to get the date-time string in UTC datetime format using the Magic Xpi function of the Start Date of Salesforce Trigger.

 

Start Date of Salesforce Trigger:-

In Salesforce Trigger-Start Date, we can only use global variables for retrieving the data.

First, we need to define the global variables, as shown in the below picture.

We have used the following functions in XPI with which we can return the date and time in UTC format.

 

1.UTCDate()

2.UTCTime()        

The lastest datetime will be shown in the SFTrigger.xml file under %InstallationDir%Runtime%Projects%’Projectname’%Salesforce%SFTrigger.xml

Note:
This is not explained in Magic XPI help under  ”Start Date description in the Salesforce - Trigger Configuration section” so we have opened a documentation bug #MXPI-29110
