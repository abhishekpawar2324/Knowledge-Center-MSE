Magic Global Support : How to Disable the javaw.exe process for DataAnalytics

Created by Amjad Madre on 31,May, 2023


This is a process that collects license usage analytics.
It can be used by the PS to analyze license usage peaks to resolve issues with the stuck processes or license errors.

But this process can consume high memory.


To disable this, you can make changes in the magicxpi-gs-agent.bat file.
Present at <installation folder>\Runtime\Gigaspaces-xpi\bin\magicxpi-gs-agent.bat

Changes to make:

Comment out the following lines like this:


@rem cd %MAGIC_XPI_HOME%\Runtime\DataAnalytics\

@rem call DataAnalyticsInstaller.bat

**Make sure to redeploy Gigaspace:
You need to stop all the XPI services before renaming the folders.
Please rename/delete the "deploy", "work" and "logs" folder.
You will find these folders under the Gigaspaces folder.

  • Runtime\Gigaspaces\deploy

  • Runtime\Gigaspaces\work

  • Runtime\Gigaspaces\logs

 

OR

 

Disable the DataAnalytics process from the DataAnalytics properties file present
in <XPI installation folder>\Runtime\Config\DataAnalytics.properties

The following changes are needed to make in this file DataAnalytics.properties

start.data.analytics=false


[following property is Hidden by-default, so need to add explicitly]
stop.data.licensesummary=true
purge.job.enable=false

**Make sure to redeploy Gigaspace.

Please rename/delete the "deploy", "work" folder.
