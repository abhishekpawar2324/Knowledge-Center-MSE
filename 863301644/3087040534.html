Magic Global Support : Users cannot delete a flow created by clicking the "Generate Flows" button in RESTful API Services.

Created by Shweta Salunkhe on 17,Dec, 2024

Description

When trying to delete a flow created by clicking the "Generate Flows" button in RESTful API Services, right-clicking the flow in the Solution Explorer, and opening the menu, there is no "Delete" and the flow cannot be deleted.

Solution:

It works as defined.

If a BP has only one flow, then “Remove” option is not available:

For example:

Create new project with one flow:

As we can see - “Remove” option is not available:

After adding second flow “Remove” option is available for both flows:

The same with generated follows from RESTFul API:

“Remove” option is not available because only one flow is generated.

If more than one flow generated, then “Remove” option is available:
