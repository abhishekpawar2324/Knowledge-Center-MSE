Magic Global Support : FTP: Error "Connection to requested FTP server could not be established. The key format is not a supported format" with 4096-bit SSH RSA key.

Created by Amjad Madre on 31,May, 2023

Objective:

The customer was trying to connect with the SFTP server using FTP Connector and while validating the resource got an error as below:
"Connection to requested FTP server could not be established. The key format is not a supported format."

Using 2048 bit SSH RSA key earlier, they were able to validate the FTP resource in xpi.

Customer wants to know if the 4096-bit SSH RSA key is supported with FTP Connector.

Solution:

We review it with our product management and after comparing it with our product specification got the following information.

The FTP connector does not yet support PPK version 3 keys.

Please check the version of the PPK key in use for FTP Resource and make sure it is of PPK Key version 2.

We can easily check the PPK file version with Notepat++.
See the below screenshot for the difference between PPK file versions 2 and 3.

The user will have to create the PPK key with version 2 and use it in the FTP resource to resolve this issue.

PuTTY (PuTTYgen) 0.75 uses a new format for SSH private key (PPK version 3)

To Generate PPK version 2 key with PuTTYgen 0.75 (or later) see the below link for reference:
https://ccportal.ims.ac.jp/en/node/2914
