Magic Global Support : How to change username/password for XPI 4.14 Magic Monitor externally

Created by Prachi Palande on 02,Apr, 2024

You can change the XPI 4.14 Magic Monitor password externally through VS Code Studio.

Steps to change the password.

  • Open VS code

  • Go to NoSQL and create a connection.

  • (If extension is not present, add the VS code Redis extension.)

  • Add Mongo DB Connection

  • Add Hostname. (For example- itsmagic.mes.ind)

  • Auth database - MGXPI414

  • Save and Connect

  • Go to connection itsmagic.mes.ind@27017 and expand

  • Expand ifs_settings

  • You can see the following screen and can change the password.
