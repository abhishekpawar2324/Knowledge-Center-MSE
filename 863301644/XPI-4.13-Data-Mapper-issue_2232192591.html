Magic Global Support : XPI 4.13-Data Mapper issue

Created by Amjad Madre on 31,May, 2023

Problem :

In XPI 4.13 when using Data Mapper, all connections are lost from migrated projects if we refresh the Database or if we modify the SQL statement manually.

You come across this problem in below two scenarios.

Scenario 1: After upgrading a project from previous versions (even from 4.12), when we open the data mapper with a source database and we right-click/refresh on the Database relevant root, all the connections are lost.

Scenario 2: If we modify the SQL statement manually and add a new field to an existing select - all connections are lost.

We could notice that when this happens, all Database fields in 4.13 are switched to UPPERCASE, while previously they were lowercase, and we assume this is the reason why the connections are lost.

Solution:

We have an isolated fix for this.

-Dll's attached.

-Replace the files 'DBWizard.resources.dll' and 'iBolt.resources.dll' in the destination into 'en' folder, 'ja-JP' folder, and in 'Application' folder which are located at
"Magicxpi413(Project installation folder)\Studio\Extensions\Application"

Note: Please keep a backup of old files outside of the magic installation.
