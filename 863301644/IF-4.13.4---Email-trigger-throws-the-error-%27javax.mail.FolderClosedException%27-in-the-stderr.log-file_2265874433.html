Magic Global Support : IF 4.13.4 - Email trigger throws the error 'javax.mail.FolderClosedException' in the stderr.log file

Created by Prachi Palande on 21,Jul, 2023

Isolated fix applicable version – XPI 4.13.4

Fixed version: XPI 4.14.1

Problem Description:

The email trigger did not respond sometimes and throws the below error in the stderr.log file:
javax.mail.FolderClosedException: * BYE JavaMail Exception: java.io.IOException: Connection dropped by server?

 Mail is not processed and remains in the mailbox.

 

Instruction to use the fix:

The following are the steps need to be done:

emailifc.ecf-> Ecf file needs to be copied to <installation folder>/Runtime/ifclib/email/emailifc.ecf

Email.dll-> Dll file needs to be copied to <installation folder>/Runtime/ifclib/email/Email.dll

mgxpi-ifc-email.jar-> Jar file needs to be copied to <installation folder>/Runtime/java/lib/mgxpi-ifc-email.jar

Note: Please stop all the projects and services before applying the fix.
Rename the work, deploy, and logs folder from <installation folder>\Runtime\Gigaspaces folder
then start the services.
