Magic Global Support : Unable to Debug the project having scheduler as a trigger from the studio, if kept the 'Scheduler window' open.

Created by Amjad Madre on 31,May, 2023

Problem Description:

In XPI 4.13.1 version

Unable to debug the project having scheduler as a trigger, if kept the 'Scheduler window' open while debugging it from the studio.

As the debugger stops working and throws an error like below:

  • Retrieving data from the space failed. Check the connectivity to the Space or your environment configuration.

  • An error occurred during the Start process. The Debug session will terminate. Check the logs for more information.

Solution:

After this, customer is not able to debug any project from the studio, even if the project does not have a scheduler in it.

Restarting the debugger service as well as the whole machine did not resolve the issue.

Steps to solve the issue:

  • Debug the project from the studio.

  • Close the 'Scheduler window' which is still open.

  • Click Ok on all error windows and wait till the project gets stopped.

  • Now debug the project again, no error will be observed and will be executed properly.
