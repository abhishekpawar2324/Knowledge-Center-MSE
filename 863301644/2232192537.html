Magic Global Support : Problem: When FTP does not get connected from Magic XPI.

Created by Amjad Madre on 31,May, 2023

Solution:

To solve this problem, try the following:

  1. Connect from another FTP client, such as FileZilla, on the same workstation.

  2. Ensure that the IP address (where Magic xpi is installed) is in the Allowed IP address List of that FTP server, meaning that the IP address of your machine is allowed by the FTP server.

  3. Check if the FTP server has allowed your IP address to connect in Explicit connection mode, since currently Magic xpi only supports Explicit mode.

  4. Sometimes, if the FTP server is frequently changing the certificate (for security purposes), the connectivity problem occurs. 

If this is the case, you can load as the Server certificate, the root (CA) certificate that issues those server certificates. As long as the newly issued certificate is issued by this CA, it will be trusted without the need to do anything else. 
At the same time, check that the CN (Common Name) of the certificate that the server is providing is identical to the server's actual hostname.X
