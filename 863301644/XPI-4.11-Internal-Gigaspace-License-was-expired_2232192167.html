Magic Global Support : XPI 4.11 Internal Gigaspace License was expired

Created by Amjad Madre on 31,May, 2023

-XPI 4.11 Internal Gigaspaces License was expired -
Symptoms: Gigaspaces components have stopped working as of April 1st, 2020 in your Magic XPI 4.11 environment. (e.g. you see your monitor screen look like this:

The problem observed is confined to XPI 4.11, which was removed from general availability in favour of 4.12.
Magic Xpi 4.11 Gigaspaces license was valid through 31 March 2020. Magic Xpi 4.11 uses the 12.3 version of Gigaspaces (GS), which is common to the 4.12 release, which has an updated GS license. We suggest that you either migrate to Magic xpi 4.12, or use the license file, as provided below.
Upgrading the license file in 4.11
*Note{*}: Please do this in a Non-Production environment and test, then proceed with the change in production. The Gigaspaces service should be stopped first, so it will require a brief window of downtime.
The license file goes by the name "xap-license.txt" under the
%InstallationDir%/Runtime/Gigaspaces folder.
Edit the file in a text editor and replace the text, starting with the word "Product…" with one of the two options below (both are valid)
Product=XAP;Version=12.3;Type=PREMIUM;Customer=Magic_Software_Magic_xpi_PROD;Expiration=2021-Aug-31;Hash=OPNQSPNYwOkAajW3X1PI
OR
Product=XAP;Version=12.3;Type=PREMIUM;Customer=Magic_Software_PROD;Expiration=2020-Dec-31;Hash=PIAOIKQNwNxNbVqDNTFI
See the screenshot below.

**You need to restart the services after the changes so that Gigaspaces will read the new license file and proceed to deploy the Gigaspaces components. Once the services are restarted, you should once again see the three green status bars indicating that everything is running correctly.

For reference:-
https://docs.gigaspaces.com/xap/12.3/started/license-key.html
