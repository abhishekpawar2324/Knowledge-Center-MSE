Magic Global Support : Incorrect invocation time is displayed on the 'Scheduler Tab' in xpi magic monitor.

Created by Amjad Madre on 31,May, 2023

Objective:

The customer is using the 'scheduler' trigger to invoke the flow.
However, they observed that the invocation time displayed on the 'Scheduler Tab' is shown as AM for the time between 12:00 PM to 12:59 PM.
After 12 PM till 1 PM, the time is shown as AM instead of PM.

The execution is working fine but the user gets confused with the displayed time.

Solution:

This issue is only observed with the old magic monitor.
However, in the new beta monitor (which comes with xpi 4.13.5 version) it is not reproduced,
and the schedular invocation time on the 'Scheduler Tab' is correctly displayed as PM for a time between 12:00 PM to 12:59 PM.

So our product management has decided to won't fix this issue with the old monitor.
Users can use the new(beta) monitor to avoid this issue.
