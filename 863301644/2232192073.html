Salesforce/Rest Client Oauth problem (Browser Control fails) 
To resolve this issue, you will need to go to registry editor and make a few changes.
What is Registry Editor?
The Registry Editor contains information, settings, options and other values of programs and
hardware installed on all versions of Microsoft Window Operating systems.


When you install a program (e.g. Salesforce Authentication), go to Registry editor and then the following path
HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Microsoft\Internet Explorer\\Main\Feature Control\FEATURE_BROWSER_EMULATION.


Right click under the default entries and add a DWORD 32-bit entry here.
Once it is added, modify the entry as following:
"MgxpiStudio.exe"=00412710

Once this is done, its authentication is added to the Windows Registry.
