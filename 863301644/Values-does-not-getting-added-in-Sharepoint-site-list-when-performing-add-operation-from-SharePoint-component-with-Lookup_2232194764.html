Magic Global Support : Values does not getting added in Sharepoint site list when performing add operation from SharePoint component with Lookup

Created by Amjad Madre on 31,May, 2023

Problem Description:

We have created the List and inside that, we have created a lookup field in SharePoint through the browser and were able to get the values in XPI through the Sharepoint component.

But when trying to perform Add operation with inserting values in lookup, the lookup values do not get updated inside the SharePoint site list.

The following issue got reproduced in XPI 4.13.5

Solution:

The value for lookup cannot be just a string - it is in the format

199;#name

where 99 is the id of the lookup and name is the name of the lookup. It cannot be a random string. Note the # is required.

 A lookup stores its value in an encoded format of ID in Source List;#Value in Source List. We need to pass a value in this format when calling UpdateListItems.
