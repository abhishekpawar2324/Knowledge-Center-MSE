Sending HTTP Body in HTTP Trigger

Problem:

You want to receive the raw HTTP body (such as JSON or XML) in a Magic XPI HTTP Trigger flow and process it dynamically during runtime.
However, by default, Magic XPI does not save the HTTP body into any variable unless specific configuration is enabled.

This is required when external systems send payloads in the HTTP POST request body, and you need to extract and use the full body content within your flow logic.

Cause:

Magic XPI's HTTP Trigger does not automatically store the POST body content unless explicitly configured.
This behavior exists to prevent unnecessary memory usage, especially for large payloads, unless the content is required by the integration logic.

Solution:

To capture the entire HTTP POST body into a Magic XPI variable, follow these steps:

  1. Modify the mgreq.ini File

Open the following file:

Navigate to:

<MagicXPI Installation Folder>/Runtime/scripts/config/mgreq.in

In the [MAGIC_ENV] section, add or update the following line:

HttpVars=MG_POST_BODY

This setting enables Magic XPI to capture the HTTP request body.

  1. Restart IIS

 

After updating the configuration file, run:

Iisreset

This is required to apply the new settings.

 

  1. Use the C.HTTP_Body Variable

The full HTTP request body will now be stored in the C.HTTP_Body context variable.
As shown in the screenshot below, this variable is of Blob Type:

📌 C.HTTP_Body – Body of HTTP request (Blob Type)

You can use this variable to save the incoming data, parse it (e.g., JSON/XML), or log it for debugging.

Flow Steps:

  1. HTTP Trigger receives the POST request.

  2. C.HTTP_Body holds the raw payload.

  3. Next steps (e.g., Expression/Data Mapper) parse or save the value.

 

Postman response:

Additional Considerations:

  • You must handle the Blob type carefully—convert it to string if needed for parsing.

  • Add logging for debugging incoming data.

  • Ensure request payloads are within safe size limits.

Conclusion:

By enabling MG_POST_BODY in mgreq.ini and using the C.HTTP_Body context variable, you can access and process full HTTP POST request bodies within Magic XPI.
This enables better integration with external systems that send structured data.
