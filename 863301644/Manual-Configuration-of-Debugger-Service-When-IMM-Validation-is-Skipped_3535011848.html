Magic Global Support : Manual Configuration of Debugger Service When IMM Validation is Skipped

Created by Abhishek Pawar on 25,Jul, 2025

Overview

In Magic xpi 4.14.1, if IMM validation is skipped during installation, the Debugger service is not automatically registered. Even after manually configuring the IMM host using the IMM_Updater.ps1 script, the debugger service will remain missing. This article explains how to manually register the Debugger service in such cases.

Scenario

  • IMM was not configured during installation (validation skipped).

  • The IMM host was configured later using: XPI4141\InMemoryMiddleware\imm-updator\IMM_Updater.ps1

  • Communication with IMM is successful, and the .env and magic.ini files are correctly updated.

  • However, the Magic XPI Debugger service is not created.

Root Cause

When IMM configuration is skipped during installation, the installer does not trigger automatic Debugger service registration. Running the IMM_Updater script only sets the IMM configuration — it does not register the Debugger service.

Resolution

You can manually register the Debugger service using the following steps:

Step-by-Step: Manually Create Debugger Service

  1. Open Command Prompt as Administrator.

  1. Navigate to the Debugger directory:

   cd C:\xpi\xpi141\Studio\Debugger

  1. Run the following command:

   Install_Debug_services.bat 4.14

  1. You should see confirmation that the 'Magic XPI Debugger 4.14' service was created.

Additional Information

The Debugger service will also be registered automatically the first time a project is run in debug mode — but only if IMM is already configured properly.

Use the manual method above when the IMM configuration was done after installation.

Best Practice

If possible, always configure IMM during installation to avoid service registration issues. If skipped, ensure both:

  • IMM is configured using the IMM_Updater.ps1

  • Debugger service is created manually as shown above.
