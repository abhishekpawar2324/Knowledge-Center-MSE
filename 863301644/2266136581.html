Magic Global Support : (Restart-on-exit[NEVER])

Created by Vaishnavi Marathe on 21,Jul, 2023

When a warning is thrown in the GSA Logs.

As an example:

GSA WARNING[com.gigaspaces.grid.gsa]:Abnormal termination with exit code[255].removing(restart-on-exit[NEVER])

 

  • This may result in the project failing to start in XPI.

-This problem is caused by the license file that is currently in use.

-To get the projects started, we need to request a new license file.

 

In addition, the license-related error can be seen in the IFS.log file.

 

We can also check the HostID in the license file.

We can generate the hostid using the 'Mgxparuntime.exe -GHI' command and compare it to the hostid in the license file.

Can also verify the expiration once of the gs-license.txt from "XPI/Runtime/Gigaspaces".
