Magic Global Support : Calendar Query operation Error 1150 Exchange call error, the request failed https

Created by Amjad Madre on 31,May, 2023

The customer was trying to use the Exchange connector to query Calendar using the OAuth2 validation.

The resource validation was successful without any error but at runtime following the error observed.

Error 1150: Exchange call error, com.magicsoftware.ibolt.exchange.IBExchangeException: calendarQuery (Exception): com.magicsoftware.ibolt.exchange.IBExchangeException: The request failed. https

Checked the resource configuration and observe Scope parameter was missing for Calendar, so added it as follows.

- openid offline_access https://outlook.office365.com/EWS.AccessAsUser.All Calendars.ReadWrite

After this the error observed was different than the first, which lead us to check the Azure Application used for resources.

Checked the API permissions assigned to the Azure application and observed no permissions for Calendar added.

So, added the following permissions to your application.

- Calendars.Read

- Calendars.Read.Shared

- Calendars.ReadBasic

- Calendars.ReadWrite

- Calendars.ReadWrite.Shared

This resolved the error and able to query the Calendar using Exchange resource.
