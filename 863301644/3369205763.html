Magic Global Support : How to start the project if it doesn't auto-start, despite the correct projectStartup.xml configuration in cluster servers?

Created by Vibha Khanke on 12,Apr, 2025

Description:

An issue was raised by the customer where they were unable to auto start the project, when described in projectsStartup.xml.

Solution:

Please apply these changes on both servers and restart the XPI services:

  • Navigate to `Magic XPI\Runtime\Gigaspaces-xpi\config\gsa\` and update the following files:
    `mgdeploy.xml`, `mginfo.xml`, and `mgmirror.xml`.

  • In each of the files, increase the `<argument>-timeout</argument>` parameter from 120 to 240 (the value is in seconds).

The default value is 120.

  • Rename the old "Deploy" and "Work" folders located in the `Magic XPI Installation Folder\Runtime\Gigaspaces`.
