Magic Global Support : How to turn off Gigaspace logs which are generated every 5 seconds.

Created by Amjad Madre on 31,May, 2023

Platform Line: Magic xpi

In Magic xpi Gigaspace logs are generating after 5 seconds.

 

Objective:

How to turn off Gigaspace logs which are generated every 5 seconds.

 

Problem:

If you experienced a scenario where Gigaspace logs generated automatically then the following is the solution will help you to turn off the logs in Gigaspace.

 

 

 

Solution:

The solution needs to do the following.

The GigaSpaces logs are always generated after starting the GigaSpaces services.

If you want to turn off Gigaspaces logs, then log off the logging of Gigspaces from the below steps.

  • Stop the GigaSpaces services.

 

  • IN "%XPI_INSTALLATION%\Runtime\GigaSpaces\config" folder there is a file 'gs_logging.properties'

Inside you can see names of GigaSpaces java modules, with the level, you can change the level to OFF, this will disable it.

You need to log Off the loggings from below.
