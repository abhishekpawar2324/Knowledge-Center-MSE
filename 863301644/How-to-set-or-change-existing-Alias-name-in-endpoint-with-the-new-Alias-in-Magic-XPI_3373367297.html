Magic Global Support : How to set or change existing Alias name in endpoint with the new Alias in Magic XPI

Created by Pooja Thakkhi on 14,Apr, 2025

Scenario: The customer is trying to change the web endpoint alias from "Magicxpi4.14.1" to "magic". They updated the alias in the project settings and restarted the Agent, Project, and IIS. However, when testing the new endpoint with "magic", it still points to the old alias "Magicxpi4.14.1".

Step-by-Step Instructions

  1. Create an Alias in IIS

To define the alias under IIS:

  1. Open IIS Manager.

  2. Navigate to:

  3. Right-click on Default Web Site and choose Add Website

  4. Set the following:

Alias: Magic

Application Pool: Assign the appropriate pool (MagicxpiAppPool_x64)

Physical Path: Point this to your scripts folder (D:\XPI\4.14\1411\Runtime\scripts)

  1. Click OK to apply the changes.


  1. Configure the Alias in Magic xpi

  •   Open Magic xpi Studio.

  •   Go to:

Project > Settings > General Environment > Internal Environment Variables

  •  Set Alias name as ‘Magic’


  1. Apply the Changes

After completing the above configurations

  •  Restart IIS

  •  Restart the Magic xpi Agent

  •  Restart the Magic xpi Project

 

Conclusion:

The alias in the project settings alone does not change the IIS configuration. The new alias "Magic" must also be created in IIS under the Default Website to reflect the change.
