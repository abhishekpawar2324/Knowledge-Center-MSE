Magic Global Support : How to find the overall count of used license in monitor XPI 4.14?

Created by Shweta Salunkhe on 17,Dec, 2024

You will need Python installed - and the redis module - run  "pip install redis" to get that.

Only print on every run - parts in red - to be fill in to you system values.

import redis

from redis.commands.search.query import Query

 

r = redis.Redis(host='10.9.4.210',port=6379, username='xpiqa',password='xpiqa')

 

index_name = 'idx:LicenseFeature'

query_string = '@licenseFeature: IBNPSRV'

query = Query(query_string).return_fields('licenseCount').paging(0, 1)

LicAvailable = r.ft(index_name).search(query).docs[0].licenseCount

print ("Available License: ", LicAvailable)

 

 

index_name = 'idx:WorkerData'

query_string = '@licenseStatus: CHECKED_OUT, @licenseFeature: IBNPSRV'

query = Query(query_string).return_fields('licenseCount').paging(0, 1)

LicUsed = r.ft(index_name).search(query).total

print ("Consumed Licenses: ", LicUsed)
