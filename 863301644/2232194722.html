Magic Global Support : Datamapper: 'Invalid SQL Statement' error occurred with the flow variable in the where clause.

Created by Amjad Madre on 31,May, 2023

Objective:

The customer has observed an error as 'Invalid SQL Statement' in 'Datamapper' when they use a flow variable in the where clause with the default value set as DStr (Date (),' YYYYMMDD')

Solution:

This is the definition - the variable used on the source side must have a concrete value so that the statement can be evaluated on the studio side.
The default value you mentioned is a runtime value which results invalid when the studio parsing process takes place.

The value in the variable default value column must have a concrete studio value and not a complex expression that is evaluated by the server at runtime.

“DStr (Date (),' YYYYMMDD')” - This is a runtime value that can be evaluated by the server (xpa engine) only.

“'20220712” - This is a studio value - concrete value that can be used to parse the statement.

It is also mentioned in the help documentation under Home > Reference Guide > Utilities > Data Mapper Utility > Source and Destination Properties Panes > Database Schema Properties > Creating an SQL Statement
