Magic Global Support : Working and Setup of OPC UA server for XPI OPC connector

Created by Amjad Madre on 31,May, 2023

Introduction to OPC:

  • 1. OPC UA (short for Open Platform Communications Unified Architecture)

  • 2. OPC Unified Architecture (OPC UA) is a machine-to-machine communication protocol for industrial automation developed by the OPC Foundation.

  • 3. Based on client-server communication.

  • 4. Focus on communicating with industrial equipment and systems for data collection and control.

OPC UA requirements and Use:

  • The basic requirement for using OPC UA for industrial 4.0 communication is a network based on the Internet Protocol (IP).

  • In xpi OPC UA is used Read-only implementation

  • IOT and Automation

OPC UA configuration and UA client:
•Kepserver

Setting Configuration:

  • In the Start Menu, search for kepServer and open the kepServer configuration

 

  • Navigate to Tray. Right click on KepServer and select  OPCUA Configuration option. Below screen will open.

 

 

  1. Click on Add. Select Network Adapter – Realtek, Port – 49321, Security Policy – None. Click on Apply and OK. Refer below screen.

 

  1. Navigate to KepServer Configuration Edit -> Properties

  1. In OPC UA menu, set Allow anonymous login to Yes.

  1. Reinitialize it from Runtime -> Reinitialize

 

 

 Now Validate the resource in xpi studio.
