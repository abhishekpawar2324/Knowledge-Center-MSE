Magic Global Support : TCP Listener trigger service has command line requester timeout setting considered from mgreq.ini

Created by Amjad Madre on 31,May, 2023

When there is no timeout defined i.e 0 in Magic xpi project for TCPListner.
We received “Server response: 7002 : Server Error<The externalResponse is NULL!>” in 30 sec.

To execute the request of 60sec correctly with the response using TCPTool and Python/JCC XPI(ref https://magicsoftware2.atlassian.net/browse/MXPI-19584 )

You can try after increasing the setting from requester timeout to 120sec(RequesterTimeoutSec = 120) in mgreq.ini from %installation%/Runtime.
This works correctly as expected with the TCPListener trigger.

For reference:-
Command Line requester timeout:30sec by default.
https://magic.secure.force.com/PublicKnowledge/articles/bl_Reference/Mgreqini-xpi-413

We added this information in the known issues in Magic xpi 4.13.1 hotfix release note.
