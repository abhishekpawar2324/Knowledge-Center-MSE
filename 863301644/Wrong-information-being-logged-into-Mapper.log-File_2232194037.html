Magic Global Support : Wrong information being logged into Mapper.log File

Created by Amjad Madre on 31,May, 2023

The customer is using the Datamapper to insert the records into the table.

Even though there are no errors after executing the Datamapper step and records are inserted into the table successfully.

The customer observed the following statement in the Mapper.log:

"The SQL statement that caused the error is too long and therefore cannot be written to the error log. For more information about the problematic SQL statement, you can enable a gateway log instead.“

 

This may lead to unnecessary confusion among the users that there is something wrong with the insert statement though it is not the case here.

  • The given table has 212 columns

  • On running the project, Data gets inserted into the table without any errors in the Database.

  • No errors were received while debugging the project.

  • No errors were observed in the magic monitor.

  • Mapper.log file under <XPI_installation>\Runtime\Logs folder.

  • The issue is reproduced in XPI 4.13.1 & 4.13.3 versions.

  • Bug: MXPI-24750 is opened for this issue and it will be evaluated in XPI 4.14 version.

  • See attached project with table script for your reference.
