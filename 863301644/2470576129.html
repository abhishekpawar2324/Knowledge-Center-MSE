Magic Global Support : How to Install and Connect PostgreSQL Database In Windows(XPI)

Created by Vaishnavi Marathe on 01,Mar, 2024

To connect and use the PostgreSQL database we have the following pre-requisites:

-PSQl application installer.

-PSQL ODBC Drivers for the specific version (32 and 64 Bit)

 

·        Visit the PostgreSQL Download Page:

Go to the official PostgreSQL download page at https://www.postgresql.org/download/windows/

Select Version:

Choose the version that you want to install. The page may display the latest stable version by default.

 

·        Select the Installer:

Choose the installer that corresponds to your Windows version (32-bit or 64-bit).

 

·        Download  and Run the Installer:

Click on the download link to start downloading the installer. Save the installer file to your computer.

Locate the downloaded installer file and double-click on it to run the installer.

 

·        Select Components:

During the installation process, you may be asked to select the components you want to install. Make sure that the "PostgreSQL Server" option is selected. You may also choose to install additional tools and libraries..

·        Select Installation Directory:

Choose the directory where you want PostgreSQL to be installed. The default directory is usually fine for most users.

 

·        Set Password for PostgreSQL Superuser:

During the installation, you'll be asked to set a password for the PostgreSQL superuser (postgres). Choose a strong password and remember it.

 

·        Select Port:

Choose the port number that PostgreSQL will use. The default port is 5432, and you can usually leave it as is unless you have a specific reason to change it.

 

·        Complete the Installation:

Follow the remaining installation steps, and wait for the process to complete. The installer will create the necessary databases and start the PostgreSQL service.

 

·        Finish Installation:

Once the installation is complete, you'll see a completion screen. Ensure that the checkbox to launch Stack Builder is unchecked (unless you want to run it immediately), and click "Finish."

 

·        Verify Installation:

Open the psql command line or pgAdmin (a graphical administration tool that comes with PostgreSQL) to verify that PostgreSQL is installed and running properly.

 

 

For 32-bit PostgreSQL ODBC Driver:

  1. Download and Install 32-bit PostgreSQL ODBC Driver:

    • Go to the official PostgreSQL ODBC Driver download page. https://www.postgresql.org/ftp/odbc/versions/msi/

    • Download the 32-bit version of the driver installer.

    • Run the installer and follow the installation instructions.

  2. Configure System DSN:

    • Open the ODBC Data Source Administrator for 32-bit systems. You can find it in C:\Windows\SysWOW64\odbcad32.exe.

    • Go to the "System DSN" tab.

    • Click "Add" to create a new System DSN.

    • Choose the PostgreSQL ODBC driver from the list.

  3. Configure Connection Details:

    • Fill in the necessary connection details, including the database name, server, port, username, and password.

    • Test the connection to ensure it works.

For 64-bit PostgreSQL ODBC Driver:

  1. Download and Install 64-bit PostgreSQL ODBC Driver:

    • Visit the official PostgreSQL ODBC Driver download page.

https://www.postgresql.org/ftp/odbc/versions/msi/

  1. Download the 64-bit version of the driver installer.

  2. Run the installer and follow the installation instructions.

  3. Configure System DSN:

    • Open the ODBC Data Source Administrator for 64-bit systems. You can find it in C:\Windows\System32\odbcad32.exe.

    • Go to the "System DSN" tab.

    • Click "Add" to create a new System DSN.

    • Choose the PostgreSQL ODBC driver from the list.

  4. Configure Connection Details:

    • Fill in the necessary connection details, similar to the 32-bit configuration.

    • Test the connection to ensure it works.
