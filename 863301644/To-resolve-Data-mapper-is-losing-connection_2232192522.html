Magic Global Support : To resolve Data mapper is losing connection

Created by Amjad Madre on 31,May, 2023

Product Line : Integration Platform

Objective : To resolve Data mapper is losing connection caused by capital letters after migrating the project from older XPI version to PI 4.13

Solution: This is a known issue to us and will be fixed in a future version of XPI (i.e.4.13.1). However we have an isolated fix for 4.13 to resolve this issue. Please find the attached isolated fix.

Steps to deploy hotfix:

1)First take the backup of dll (DBWizard.resources.dll,iBolt.resources.dll) from location (<<XPI_installation_folder>>\Studio\Extensions\Application\en)

2)Download the attached isolated fix.

3)Unzip the fix.

4)Now from the "en" folder replace the dll (DBWizard.resources.dll,iBolt.resources.dll) to the location (<<installation_folder>>\Studio\Extensions\Application\en)

5)Restart the studio and check if the issue is resolved or not. Additional continued steps to follow if you still face the same issue.

6)take backup of dll(DBWizard.dll,iBolt.dll) from location (<<XPI_installation_folder>>\Studio\Extensions\Application)

7)Then replace the dll (DBWizard.dll,iBolt.dll) from attached isolated fix to the location (<<XPI_installation_folder>>\Studio\Extensions\Application)

8)Restart the studio and check if the issue is resolved.
