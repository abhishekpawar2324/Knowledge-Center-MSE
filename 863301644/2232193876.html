Magic Global Support : XML External Entity Reference (XXE) Vulnerability in Apache log4net

Created by Amjad Madre on 31,May, 2023

Magic Studio uses Log4net.dll.

Isn't it affected by the XML External Entity Reference (XXE) vulnerability in Apache log4net?

https://security.snyk.io/vuln/SNYK-DOTNET-LOG4NET-568897

We have the following update for this scenario from Product Management.

XXE (XML eXternal Entity) is a type of attack that takes advantage of external entities in XML files. Some websites rely on XML for transferring data between the browser and the webserver. When it receives data in XML, the web server transmits it to an XML parser which processes this data.

So even though, Apache log4net versions before 2.0.10 do not disable XML external entities, the studio will not be impacted since there is no such browser/server communication existing.
