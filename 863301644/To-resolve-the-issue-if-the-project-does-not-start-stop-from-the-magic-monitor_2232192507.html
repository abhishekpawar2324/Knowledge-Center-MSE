Magic Global Support : To resolve the issue if the project does not start stop from the magic monitor

Created by Amjad Madre on 31,May, 2023

Product Line: Integration Platform
Objective : To resolve the issue if the project does not start/stop from the magic monitor and to see the project in monitor.

Solution: We can follow the below steps to resolve this issue:
1)Project needs to be build once before starting from the monitor.

2)Please check the java_path on runwebmonitor.bat file, which is located under the <Magic xpi installation>\Runtime\RTView\magicmonitor\runwebmonitor.bat folder. If not present please set the JRE_HOME path as it is for JAVA_HOME(e.g set JAVA_HOME=%MAGIC_XPI_HOME%\Runtime\Jre). Restart the services and check it again. Otherwise, Please Run the runwebmonitor.bat from Admin command line manually,service should be stopped for Magic Display server(i.e monitor services). and check it again to start the project.

3)Please delete the below files from the project folder: - start - start.xml - start.xml.triggers - stop And build the project in a studio and then try to run on the monitor.

4)Please try using Internet Explorer with adding "localhost" compatibility settings.We recommend the Internet explorer for Magic Monitor.

5)Please check the path defined in applicationlist.xml and the project directory are the same. you can find applicationlist.xml at location,".. XPI-installation directory\Runtime\Config\ApplicationsList.xml"

Now build the project on the same machine, you are using the magic monitor on. Only build projects are going to visible in the monitor
