Magic Global Support : Magic xpi gets memory shortage within GSC due to the Email attachment.

Created by Amjad Madre on 31,May, 2023

GSC - Memory shortage  - *Due to email trigger attachment - IFS.ini    
[MAGIC_IBOLT]MailGetFile=Y

We have introduced a new Flag named MailGetFile here.  If the value of this flag is Y then the email content will be written to a file and Argument XML Location data will contain the path of the file.  If this is not set to Y then the behavior same as earlier one. i.e., email Content will be stored in the variable holding Argument XML Location.
Before running the project, make sure to set the following flag in IFS.ini
[MAGIC_IBOLT]MailGetFile=Y
If value of this flag is Y, the Arguments XML Location variable contains the path of the file which contains the email data.   So now this variable will contain only the path of the file where the email content is written.
If this flag is not set, then the Arguments XML Location variable will contain the email data.

For this option, we have to change the existing project.

  1. In the Datamapper step, change the source of the data as File instead of Variable.

  1. Make sure to add a step after datamapper step to delete the created file.  Else these files will remain as it is forever.

Magic XPA 4.7.2 fixed -  https://magicsoftware2.atlassian.net/browse/MXPI-6673
