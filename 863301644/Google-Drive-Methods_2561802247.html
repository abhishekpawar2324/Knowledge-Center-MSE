Magic Global Support : Google Drive Methods

Created by Monali Kadam on 22,Apr, 2024

Explanation:

The Google Drive component provides connectivity between Magic xpi and Google Drive.

When you place the Google Drive component in a flow, Magic xpi automatically opens the Properties pane for the component. You should enter the requested information in the Properties pane. Then, double-click or right-click on the component and select Configuration from the context menu to open the component's Configuration dialog box.

Before you use the Google Drive component, you should first define a Google Resource in the Settings dialog box's Resources section.

To use the Google Drive component, you must complete the OAuth 2.0 authorization flow.

Google Drive – Methods:

Use the following methods to configure the Google Drive component:

·        Create Folder

·        Delete

·        Download Item

·        Move

·        Query Item List

·        Retrieve Item List

·        Set Item Access Control

·        Update Item

·        Upload Item

Please refer below help link for details information:

I have attached ZIP of sample project for reference “GoogleDrive_BP1_Flow1”.

sample project to grant permission to files in the Google Drive connector in Magic xpi, there are two steps:

  1. Retrieve Item List: retrieves a list of all the currently authenticated user's items.

Returns an XML containing a list of items and their details.

  1. Set Item Access Control: It determines the user permission for the item.

  • KEY: The key to the item whose access control permissions you want to set.

  • Use key from previously generated XML file.

  •  USER: The user for whom you are granting access control permission.

  • RIGHTS: Determines the type of access rights that you want to give to a specific user. Select one of the following from the drop-down list: (Owner, collaborator, viewer, and No access)

You can verify in google Drive, if the rights are changes or not.
