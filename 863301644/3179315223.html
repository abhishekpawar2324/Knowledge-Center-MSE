Magic Global Support : Troubleshooting: Unable to Start IMM Agent (Error 503)

Created by Balaji Karagir on 29,Jan, 2025

Problem: When starting the IMM Agent, the following error messages are displayed in the IMM_agent.log:

2025-01-15 17:01:22:122 error AxiosAdapter: interceptor(): status:Request failed with status code 503

2025-01-15 17:01:22:122 info Failed to connect using HTTPS, falling back to HTTP...

2025-01-15 17:01:22:122 error AxiosAdapter: interceptor(): status:Request failed with status code 503

2025-01-15 17:01:22:122 error Failed to retrieve connection details.

2025-01-15 17:01:22:122 error Error to start agent:Failed to configure connection

The error "status: Request failed with status code 503" typically indicates that the server is temporarily unavailable.

Affected Versions: Magic XPI 4.14.1

Cause: The root cause of this error was traced to incorrect proxy settings on the Windows server hosting the IMM Agent. Proxy configurations were preventing the agent from establishing a proper connection.

Solution: To resolve this issue, follow the steps below:

1 Review Proxy Settings:

o   Check and update the proxy settings on the Windows server to ensure they are correctly configured.

o   If a proxy is not needed, remove any unnecessary proxy settings.

 

  1. Verify Network Stability:

    • Ensure the server running the IMM Agent has a stable and active network connection.

    • Use commands such as ping or traceroute to confirm connectivity to the required endpoints.

  2. Check Kubernetes Pod Status:

    • Run the following command to check the status of the pods:

    • microk8s kubectl get pods -A

  1. View IMM Cluster Details:

o   Execute the following command to verify cluster information:

   kubectl cluster-info

 

Verification: After making the above changes, restart the IMM Agent and monitor the IMM_agent.log to ensure no further errors are logged. The agent should now start successfully.

Conclusion: The "503" error was caused by improper proxy settings that disrupted the agent’s connectivity. By verifying and correcting the network configuration, you can resolve this issue and ensure smooth operation of the IMM Agent.
