Magic Global Support : UDS Variables/Fields sorting mechanism

Created by Amjad Madre on 31,May, 2023

We came across a case where a customer asked for UDS sorting.

 

Customers' Questions were:

 

Q)The UDS is not sorted by the items checked for index when defining the UDS.

>>The items checked for index when defining the UDS are sorted according to the index and not by values.
When you use the UDS on the source side, the sort property is available, and the sorted results are displayed in the file rather than in the context view.
We have used the UDS function for updating the specific field.
