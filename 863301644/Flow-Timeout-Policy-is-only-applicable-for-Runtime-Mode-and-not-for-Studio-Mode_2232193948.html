Magic Global Support : Flow Timeout Policy is only applicable for Runtime Mode and not for Studio Mode

Created by Amjad Madre on 31,May, 2023

Description

In Magic XPI the flow property of the Timeout policy is not applicable for the Studio Mode. This flow property is only applicable for the Runtime Mode.

 

Please refer to the sample project provided.

https://magicsoftwarecorp-my.sharepoint.com/:u:/g/personal/vaishnavi_marathe_magicsoftware_com/Ec9d43Jy37hMg4pNpWOM7RUBmZ9iMQZwrQW8Jztb4Opt7g

 

-In the above project attached, there is a timeout policy property used, and the timeout value given is 10 seconds to abort a flow. and added a delay of 20 seconds using the delay utility.

-When you debug the project from Studio Mode, you will not be able to find out the occurrence of a timeout.

 

Studio Mode results:

 

To See the Results in Monitor:

-You need to build the project first

 

Runtime Mode Results:

 In Runtime Mode you will observe the flow start/flow timeout and flow abort.You can easily see the timeout and abort of the flow with flow id.
