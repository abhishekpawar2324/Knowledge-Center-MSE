Magic Global Support : IF 4.13.6-Connecting to Dynamics NAV with OData4 returns error The request URI is not valid

Created by Prachi Palande on 02,Apr, 2024

Fixed version: XPI 4.14.1

Problem Description:

The problem is that the WSItemColorTransfer Expand object does not appear correctly in the output XML.

Error observed while connecting to Dynamics NAV with OData connector.
When attempting to connect to Dynamics NAV with OData4 using the URL http://progress-mt-t01.office.rbc.ch:7048/PROGRESS_DB04_NAS_WS/ODataV4/Company('Intersport')/WSItemColorTransfer, the metadata cannot be loaded inside the resource.
When adjusting the URL to http://progress-mt-t01.office.rbc.ch:7048/PROGRESS_DB04_NAS_WS/ODataV4/$metadata#Company('Intersport')/WSItemColorTransfer, the metadata can be loaded inside the resource, but attempting to get data from the system results in an error indicating that the URL is not well-formed.

Instruction to use the fix:

Place the files from the attached zip at following location:

·        \Runtime\addon_connectors\OData\ui\lib - ja-JP folder, en folder, OData.dll.

·        \Runtime\addon_connectors\OData\runtime\java\lib- mgxpi-odataclient.jar.

·        \Runtime\addon_connectors\OData\ - settings.dat, metadata.xml.

Note: Please stop all the projects and services before applying the fix.
Rename the work, deploy, and logs folder from <installation folder>\Runtime\Gigaspaces folder
then start the services.
