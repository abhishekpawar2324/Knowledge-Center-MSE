Magic Global Support : How to increase string / numeric picture size for default data type in XPI

Created by Amjad Madre on 31,May, 2023

By default, the picture size at destination end is set to 1000 so if customer wants to increase the picture size of String or Numeric value greater than 1000 then refer to the following screenshot:

 

Go to Solution Explorer > Repositories > Default Data Format

Max we can increase the length of Alpha is to 32000 as it's limited to that length.

If it exceeds more than 32000 characters, then you can pass the content using BLOB variable (Binary Large Object)

A BLOB variable by definition can contain any type of information and not only a string.

For example, you can load into a blob variable any type of binary information ex: images, word documents, or any other file type or information.
