Magic Global Support : Database - How to send date value as NULL

Created by Amjad Madre on 31,May, 2023

Problem Description :

Passing the data from flatfile to the database.

In the database, we have a date field for which nullable is true.

The date column is to be NULL in case the value is not available in the source file.

Solution:

We have attached the sample project.

In the project below is the condition in the calculated value, which we need to define for the date field.

-----

IF (ISNULL ( Src.S1/Record/Date ) OR DStr ( Src.S1/Record/Date ,'YYYY-MM-DD') = '0000-00-00' OR DStr ( Src.S1/Record/Date ,'YYYY-MM-DD') = '',NULL (),DStr ( Src.S1/Record/Date ,'YYYY-MM-DD'))

-----
