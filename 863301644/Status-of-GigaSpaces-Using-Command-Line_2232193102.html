Magic Global Support : Status of GigaSpaces Using Command Line

Created by Amjad Madre on 31,May, 2023

To be able to get status using the command line you need to implement zookeeper architecture.

>>First set GS_MANAGER_SERVERS=Host Name

in setenv-overrides.bat file present at

[Installation Dir\Runtime\Gigaspaces\bin\setenv-overrides.bat]

After this add –manager in the magicxpi-gs-agent.bat file.

[Installation Dir\Runtime\Gigaspaces-xpi\bin\magicxpi-gs-agent.bat]

Now when you start the Gigaspaces this will start as a Zookeeper architecture.

>>Go to Directory.

[Installation Dir\Runtime\Gigaspaces\bin\]

From this directory open the command prompt and run the below command which will display status

  • gs pu list

  • gs space list

For detailed information related to zookeeper and various commands related to Gigaspaces please refer below link

https://docs.gigaspaces.com/latest/admin/leader-election-consistency-biased.html

https://docs.gigaspaces.com/latest/admin/xap-manager.html

For commands:

https://docs.gigaspaces.com/latest/admin/admin-view-gen-space-details.html

https://docs.gigaspaces.com/latest/admin/admin-view-gen-pu-details.html
