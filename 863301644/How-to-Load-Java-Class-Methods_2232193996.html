Magic Global Support : How to Load Java Class Methods

Created by Amjad Madre on 31,May, 2023

 If you want to load the Java class methods using the java class connector step in the flow of XPI project.

 

When you try to load the java class methods without assigning the Object reference in the configuration of the step. You will find only one method in the drop-down list. Find the screenshot attached:

 

But when you assign the Object Reference to :

1)C.UserBlob

or

2)C.Http_Body

or

3)C.UserXML

 

And then try to load the methods in the drop-down list and all names are displayed. Find the screenshot attached.

Additionally:-

We can also check the class name and methods in Connector Builder by loading the jars in the DAM Methods.

You can see the same Java methods available in the drop-down list.

 

Note:

Java Version:

  • "1.8.0_192"(32-bit)

  • "1.8.0_60"(64-bit)
