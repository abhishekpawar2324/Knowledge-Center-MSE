Magic Global Support : IF 4.13.4- Increasing the limit of Rest client HTTP timeout value more than 300 sec

Created by Prachi Palande on 02,Apr, 2024

 

Fix versions -Magic xpi Future Version

Problem Description:
REST Client connector reaches Timeout in 2min 30 sec even when environment timeout set is more than 3 minutes,
returns error:
Error 752: Post operation failed. Received socket timeout exception.

In case a REST service has huge data, or the time taken for the response is more than 5 minutes it does not work in XPI.
The same works fine in POSTMAN

Instruction to use the fix:

 

Place the files from the attached zip at following location:

\Magic xpi 4.13\Runtime\addon_connectors\RestClient\runtime\java\lib\

\Magic xpi 4.13\Runtime\addon_connectors\RestClient\ui\lib\

Note: Please stop all the projects and services before applying the fix.
Rename the work, deploy, and logs folder from <installation folder>\Runtime\Gigaspaces folder
then start the services.
