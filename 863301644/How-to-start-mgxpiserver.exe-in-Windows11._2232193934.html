Magic Global Support : How to start mgxpiserver.exe in Windows11.

Created by Amjad Madre on 31,May, 2023

Officially the current version of XPI is not tested on windows11.

-There are some basic troubleshooting you can perform to make mgxpiserver.exe run on Windows11.

  1. You have to confirm if the magic xpi folder is not blocked by any Antivirus software or Windows Defender.

  2. You can try to start the magic xpa studio and see if you see the magic xpa runtime is visible in the task manager.
    Or build the project once, which is with mapper & See if the mgxparuntime.exe is visible in the task manager. This will confirm the problem is on the engine level or specific with mgxpiserver.exe.

  3. Please verify that .NET Framework 4.0 is installed on your machine. You must have .NET Framework 4
    (or above) installed on the server and on your IIS machine.
    You also might need to install the Microsoft Visual C++ 2015 Redistributable.

  4. Also check the windows firewall settings, if it is blocking the mgxpiserver from starting on the respective machine (Windows11).
