Magic Global Support : How to get more than 32000 characters inside a String in XPI using the RegEx function

Created by Amjad Madre on 31,May, 2023

The customer was using the function RegExReplace and trying to get more than 32000 characters inside a string but could not achieve it.

So, to get more than 32000 characters inside String we have come up with a workaround where using Java class connector we have to achieve the purpose.

We have created a .jar file with all the RegEx functions which we need to access inside Java Class Connector.

 

 Here is the Inside class name which we mentioned as per the class name with the package of Java code.

Inside the method, we have the function (RegExReplace) with Four parameters set with type alpha with which we achieve the purpose of getting more than 32000 characters inside String.

Here we can see we have four parameters with type alpha where first three parameters are of the Syntax of RegExReplace (Alpha RegExString, Alpha LookInString, Alpha ReplaceWith). And forth parameter for getting the data.

Attached is a .jar file, Java code, and a Sample project for reference.

Note-(We need to put the jar file inside %XPI Installation%Runtime\Java\lib. And make sure to Unblock the jar file and restart the studio once.)
