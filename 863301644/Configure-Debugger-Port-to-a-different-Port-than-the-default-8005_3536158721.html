Magic Global Support : Configure Debugger Port to a different Port than the default 8005

Created by Balaji Karagir on 27,Jul, 2025

Issue: 

The Magic XPI Debugger service stops a few seconds after starting. 

Cause: 

The service may be failing due to port conflicts. By default, the debugger uses port 8005, which may already be in use. 

Resolution Steps: 

  1. Check Debugger Service Logs 

Review the logs to confirm if port 8005 is busy. 

  1. Change the Debugger Shutdown Port 

Navigate to: Studio\Debugger\apache-tomcat-8.5.37\conf\server.xml 

Change the following line: 

<Server port="8005" shutdown="SHUTDOWN"> 

To: 

<Server port="8006" shutdown="SHUTDOWN"> 

  1. Update the Debugger Connector Port (New Info) 

The debugger service by default uses port 8095. 

Navigate to: Studio\Debugger\apache-tomcat-9.0.35\conf\server.xml 

Locate and edit the following entry: 

<Connector port="8095" protocol="HTTP/1.1" connectionTimeout="20000" redirectPort="8443" /> 

  1. Update Port on Studio Side 

Navigate to: Studio\Extensions\Application\iBolt.dll.config 

Modify the following entry: 

<add key="DebuggerPort" value="8095"/> 

  1. Restart Debugger Service 

After making these changes, restart the debugger service. It should now start successfully without stopping.
