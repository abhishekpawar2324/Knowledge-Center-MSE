Magic Global Support : Behavior change in HTTP component sent with the argument in XPI 4.14

Created by Rohan Karekar on 20,Dec, 2023

Before 4.13.4 we do not need to specify “Content-Type” in the HTTP header to use HTTP post with the argument.

From 4.14 we need to specify “Content-Type” in the HTTP header “Content-Type: application/x-www-form-urlencoded” to use HTTP post with the argument.
