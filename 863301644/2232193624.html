Magic Global Support : Can't start a project in the studio because debugging fails with an error "Data retrieval from space was unsuccessful. The debug session will be terminated "?

Created by Amjad Madre on 31,May, 2023

Please review the 10 solution points listed below to see if they can assist you in resolving this issue.

1- Check that you have started all of Magic's services.

2- Please check the status of the Magic monitor, which means whether all of the GRIDs are intact or not.

  • Navigate to your installation folder and launch Magic Monitor - check to see if all three GRIDs are still intact.

3- Next, look for the hostname in the Start.xml file, which is located in the project folders.

  • Hostname should be the IP of your machine.

4- Rename or delete the following files: Start.lnk, start.xml, start.xml.triggers, Stop.lnk, and then rebuild the project to see if that helps.

5- Check the task manager to see if any other Tomcat services are running besides magic debugger tomcat service.
If any additional Tomcat service is running in task manager besides magic debugger service then kill that process and try debugging the project again from the studio.

6- Restart the studio by deleting the 1.0 and 2.0 folders from the following location:

  • C:\Users<username>\AppData\Roaming\Magicsoftware\XPIStudio\

7- Change the port under server.xml file:

  • D:\XPI<XPI_version>\Studio\Debugger\apache-tomcat-9.0.35\conf\server.xml

<Server port="8006" shutdown="SHUTDOWN">

The reason to change the port is that- it could be the possibility that the port Tomcat is attempting to access is already in use.
BTW using following netstat command you can also check if a port is free or busy.

  • Open command prompt and enter the following command

  • netstat -ano |find "<port_no>"

This command will show whether or not the port which you trying to access is available or not.

8- Under following location remove the 'RemoteDebugger' folder and place is on Desktop (you can even delete it).

  • When you start the monitor service the RemoteDebugger.war file is executed and new 'RemoteDebugger' folder gets created again.

  • D:\XPI\MagicXPI412\Studio\Debugger\apache-tomcat-8.5.37\webapps

9- The Debugger service by default will start on the port 8095.

The value of the default port can be changed in server.xml file located under Studio\Debugger\apache-tomcat-9.0.35\conf. Locate and edit the port in the entry below:
<Connector port="8095" protocol="HTTP/1.1" connectionTimeout="20000" redirectPort="8443" />

The same change on the Studio side can be done in the iBolt.dll.config file located at path Studio\Extensions\Application. Locate and edit the DebuggerPort in the entry below:
<add key="DebuggerPort" value="8095"/>

10- Now launch the Studio open the project and press key F5 to get into the Debug Mode.

This is a list of action items to look at if you're having trouble with studio debugging.
