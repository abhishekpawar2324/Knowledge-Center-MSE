Magic Global Support : Steps to enable login to Ubuntu from Puuty and WinSCP

Created by Rohan Karekar on 03,Oct, 2023

Need to Edit sshd_config file by using below steps

Type vi /etc/ssh/sshd_config

It will open sshd_config file in Vim editor

Press the Insert key it will allow you to edit the file

Change the PermitRootLogin Yes

Set PasswordAuthentication Yes

Add below line at the end of the file

add "AllowUsers %Username%" at the end of the file

In the screenshot, I have added 2 users ‘rohan’ and ‘root’

After completing the editing press the Esc key and type :wq and press enter it will save the changes and close the file.

run command “visudo”

visudo is a special tool for safely updating the /etc/sudoers file, used by the sudo command for providing and managing privileged access.

Add following line after "%sudo ALL=(ALL:ALL)ALL"

%sudo ALL=NOPASSWD: /usr/sbin/sshd

 

Restart the Ubuntu machine to apply the changes.
