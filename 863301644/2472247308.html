Magic Global Support : The debugger failed to start with an error as "Retrieving data from space failed".

Created by Avinash Mamale on 04,Mar, 2024

Problem Description:

When tried to debug the project from the studio, it failed with an error as "Retrieving data from space failed".

Solution:

One of the reasons for this error to occur could be if the scheduler's window is left open when moving from debug mode to design mode and then moving back to debug mode. This issue can be resolved by deleting the user profile folder for Magic xpi.

For this,

1. Close the studio.

2. Navigate to the following location: C:\Users\<UserName>\AppData\Roaming\Magicsoftware\XPIStudio\2.0

3. Delete the contents of the 2.0 folder.

4. Reopen the studio and then run the debugger.

Another possible cause could be connectivity timeout to reach the Space from the Debug server. In this case, increase the debug timeout value.
