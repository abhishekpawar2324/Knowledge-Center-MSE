Magic Global Support : Manual setup oracle and set internal database of Magic xpi

Created by Amjad Madre on 31,May, 2023

Manual setup oracle and set internal database of Magic xpi

·         Install oracle server and client (SQL Developer)

·         Configure the “tnsnames.ora” file under the Installation folder\network\admin

·         Additional details only for instant client :

The reasons are :

 1.The path to the Oracle instance client is in the machine’s PATH environment variable (cmd > set path), preferably at the beginning of the path.

 2.The user running the service has authorization to the Oracle instance client and to the Magic xpi server.

 3.The problem might be because the tnsnames file cannot be reached if it is not under the same root as the running executable.

  1. Copy tnsnames.ora file in Installation folder\Runtime

  2. Copy tnsnames.ora file in Installation folder\studio

Database : 

◾ Run below mentioned database scripts.

Note: Provided database scripts are related to XPI 4.7

  • If you use higher version of XPI 4.7, please execute ‘BackUpAndCreateTable.sql’ script after executing XPI 4.7 scripts.

  • ‘BackUpAndCreateTable.sql’ scrip located at ‘%XPI_installation% \DB\ORACLE\Standard\’

 

--------------------------------------- Changes in xpi installation directory ---------------------------------

  1. Database Drivers: 

◾ Copy the database driver from Installation folder\jdbc\lib.

◾ Paste in installation folder\Runtime\Java\DatabaseDrivers.

 

  1. Magic.ini  (installation folder\Runtime\Magic xpa\Magic.ini)

◾ Change: DB_USER=C##mgxpi4_1

◾ Change: [Magic_Gateways] tag

MGDB13=Installation folder\Runtime\Magic xpa\Gateways\mgOracle.dll

 

 

  1. datasource.xml (installation folder\Runtime\Config\datasource.xml)

◾ Change:

<datasources> 

<datasource id=“2” hibernate.default_schema=“” 

hibernate.dialect=“org.hibernate.dialect.OracleDialect” 

hibernate.default_catalog = “mgxpi4_1” 

driverClassName=“oracle.jdbc.driver.OracleDriver” 

url=“jdbc:oracle:thin:@[IP_Address_Of_Oracle_Server]” 

username=“C##mgxpi4_1” password=“MagicPass#3”/> 

</datasources>

 

  1. OPTIONS.ini  (installation folder\Runtime\RTView\magicmonitor\OPTIONS.ini)

◾ Change:

sqldb mgxpi4_1 C##mgxpi4_1 MagicPass#3 jdbc:oracle:thin:@[IP_Address_Of_Oracle_Server] oracle.jdbc.driver.OracleDriver - false false

 

  1. magicxpi-setenv.bat  (installation folder\Runtime\Gigaspaces\bin)

◾ Change:

set ADDITIONAL_OPTIONS=%ADDITIONAL_OPTIONS% -Dcom.magicsoftware.ibolt.home=%MAGIC_XPI_HOME%\runtime -Doracle.net.tns_admin=[Set folder path of tnsnames.ora file without any spaces]

 

Database script : 

Open sql developer run create database and create table script as below.

 

  1. Create Database:

CREATE TABLESPACE MGXPI4_1

LOGGING

DATAFILE 'MGXPI4_1.ora' SIZE 100M AUTOEXTEND

ON NEXT 50M MAXSIZE UNLIMITED DEFAULT

STORAGE ( INITIAL 80K NEXT 1024K MAXEXTENTS 80 PCTINCREASE 0 );

CREATE TEMPORARY TABLESPACE MGXPI4_1_TMP

TEMPFILE 'MGXPI4_1_TMP.ora' SIZE 10M AUTOEXTEND

ON NEXT 10M MAXSIZE 50M;

CREATE USER C##MGXPI4_1 PROFILE DEFAULT IDENTIFIED BY MagicPass#3

DEFAULT TABLESPACE MGXPI4_1

TEMPORARY TABLESPACE MGXPI4_1_TMP;

GRANT CONNECT TO C##MGXPI4_1;

GRANT RESOURCE TO C##MGXPI4_1;

– Grant/Revoke system privileges

GRANT unlimited tablespace TO C##MGXPI4_1;

 

2.Create Table: 

 

BEGIN

EXECUTE IMMEDIATE 'DROP TABLE C##MGXPI4_1.IFS_ACTLOG';

EXCEPTION
