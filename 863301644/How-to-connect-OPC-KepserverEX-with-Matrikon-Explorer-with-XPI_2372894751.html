Magic Global Support : How to connect OPC KepserverEX with Matrikon Explorer with XPI

Created by Vaishnavi Marathe on 05,Jan, 2024

We came across one case where the customer wanted to connect XPI OPC UA with Matrikon OPC UA Explorer

 

Matrikon OPC UA Explorer:

 

Matrikon OPC UA Explorer is a free OPC Unified Architecture (OPC UA) Client packed with easy testing and troubleshooting functionality for OPC UA servers. Unlike other OPC UA clients, Matrikon OPC UA Explorer is fast, easy to use, and packed with useful convenience functions.

 

To connect to OPC UA in XPI we need the KepserverEX installed on our machine.

To install KEPserverEX please find the attached Document or Link :

QA OPC KEPServer Installation and Configuration

Till now we have tested OPC UA with the KepServerEX.

But the customer was using Matrikon OPC UA Explorer to connect the OPC with XPI

Please find the attachment on how can to connect OPC with Matrikon OPC UA explorer.

You can download Matrikon OPC UA Explorer from the following:

https://www.matrikonopc.com/opc-ua/products/opc-ua-explorer.aspx#:~:text=Matrikon%20OPC%20UA%20Explorer%20is,is%20packed%20useful%20convenience%20functions .

 

  • ·      You need to register first.

  • Once you are registered Login to the page

  • ·      Click on Download Now

  • ·      Once the setup is downloaded you can start the installation

  • ·      Accept the license agreement and click Next

  • ·      You can change the destination folder

  • ·      Check the Desktop Shortcut and click Install

Once the Installation is finished you can see the Matrikon OPC UA Explorer icon on your desktop

 After installation of Matrikon and Kepserver please follow the below to connect them.

  •  I have added a new server endpoint URL in Kepserver

  • Once it is connected it will display that the Kepserver has connected

  • You will see the Channel name and device name which is Kepserver

  • Kepserver Channel and Devices
