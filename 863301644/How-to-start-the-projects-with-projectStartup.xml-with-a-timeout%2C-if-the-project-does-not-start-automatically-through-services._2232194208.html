How to start the projects with projectStartup.xml with a timeout,
if the project does not start automatically through services.

 Steps to perform:

  • Please check the machine configuration.
    - more than 4 Core CPU
    - more then 8 GB RAM

  • Go to Magic XPI\Runtime\Gigaspaces-xpi\config\gsa\mgdeploy.xml , mginfo.xml & mgmirror.xml 
    - Increase the <argument>-timeout</argument> parameter from 120 to 240 (the value is expressed in seconds) 

  • Delete the old Deploy and work folder from Magic “XPI Installation Folder”\Runtime\Gigaspaces. 

 

 The main cause of this problem is the machine configuration, If this is not sufficient as per the minimum configuration required for XPI then projects do not start or PU deployment also fails.
