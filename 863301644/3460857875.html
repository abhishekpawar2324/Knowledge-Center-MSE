Magic Global Support : Retrieving LOGDB & IMMDB Credentials from IMM

Created by Abhishek Pawar on 04,Jun, 2025

A customer has set up authentication details (username and password) for the LOGDB used in their IMM deployment, but has lost the credentials. They need to recover the LOGDB access username and password for the IMM system to restore the database connection without having to redeploy IMM.

Solution:

To recover the MongoDB access username and password in a Kubernetes-based IMM deployment, follow these steps:

Retrieve LOGDB Credentials

To retrieve the username:

kubectl get secret log-db-secret -n magic-xpi-imm-ns -o jsonpath="{.data.username}"

To retrieve the password:

kubectl get secret log-db-secret -n magic-xpi-imm-ns -o jsonpath="{.data.password}"

Retrieve IMMDB Credentials

To retrieve the username:

kubectl get secret imm-db-secret -n magic-xpi-imm-ns -o jsonpath="{.data.username}"

To retrieve the password:

kubectl get secret imm-db-secret -n magic-xpi-imm-ns -o jsonpath="{.data.password}"

Note: Credentials will be received in Base64 format. You can decode them using a Base64 decoder.

Refer to the attached Batch file to directly access the credentials. Change the namespace in the batch file and execute it.
