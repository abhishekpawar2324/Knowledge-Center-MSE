Magic Global Support : Asterisk (*) Omitted When Reading Environment Variables in Magic XPI

Created by Abhishek Pawar on 07,May, 2025

Issue Description:
When reading an environment variable that contains an asterisk ("*") in a "Flow Data" component, the asterisk is omitted from the result. This causes issues when using GLOB patterns as the missing asterisk renders the result unusable.

For example:

  • Environment Variable: temp\*.xml

  • After reading into a Flow Variable: temp\.xml

 

 

Case Number: 00113547

 

 

Expected Behavior:
The asterisk (*) character should be properly retained when reading the environment variable, as it is not listed among the unsupported characters in Magic xpi documentation. The variable should remain as temp\*.xml or a valid GLOB pattern.

Problem:
The asterisk is omitted from the environment variable when read into the flow variable. This could impact the use of GLOB patterns, especially in use cases where pattern matching is required.

 

 

 

 

Workaround:
To temporarily address the issue, the following solutions have been suggested:

  • Use a double asterisk ** at the beginning of the pattern, i.e., *temp\*.xml to ensure that the asterisk is preserved.

  • Alternatively, using temp\**.xml results in temp\*.xml, retaining the asterisk.
