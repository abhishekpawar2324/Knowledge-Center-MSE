Magic Global Support : HTTP trigger cannot receive data if there are two Blobs arguments mapped to the respective flow variables.

Created by Shweta Salunkhe on 17,Dec, 2024

Description

For the HTTP trigger,if we take the two blob types arguments and mapped to the flow variables then
one blob is empty and we get the data only for the second blob.
Also,the data of F.blob1 (sample01.csv)is mapped to F.blob2 , and the data of sample02.csv disappears.

This phenomenon does not occur when there is only one Blob type data to be received.

Solution:

The fix is provided on top of XPI 4.14

It is necessary to copy MgWebRequester.dll file from the package to ..\Runtime\scripts\bin\ folder\

Attachments:

MgWebRequester_4_14(93) (1).zip (application/zip)
