Magic Global Support : When multiple XPI versions are installed, the connector builder does not create Connector (.NET) in the specified directory.

Created by Vibha Khanke on 18,Oct, 2024

Description:

If both Magic XPI 4.13.6 and XPI 4.14 are installed on same machine, the following issue occurs:

In XPI 4.13.6, when a .NET process is created using the .NET connector and a .NET sample project is built in Visual Studio.

However, when attempting to create a connector in the Connector Builder (XPI 4.13.6) to use the .NET class, the connector is saved in the Magic XPI 4.14 addon connectors folder instead of the intended XPI 4.13.6 addon connectors folder.

 As a result, it does not appear as a connector in the studio, even after restarting it.

 

Solution:

After updating the InstallPath in the Registry Editor, the .NET connector was successfully created in the correct XPI folder location.

 

Here are the steps we followed:

  1. Open the Registry Editor.

  2. Navigate to the following path: Computer\HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\MSE\Magic xpi

  3. Modify the InstallPath to match your current studio location.
