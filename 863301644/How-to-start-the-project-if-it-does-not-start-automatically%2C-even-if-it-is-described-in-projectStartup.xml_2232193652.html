Magic Global Support : How to start the project if it does not start automatically, even if it is described in projectStartup.xml

Created by Amjad Madre on 31,May, 2023

·       Go to Magic XPI\Runtime\Gigaspaces-xpi\config\gsa\mgdeploy.xml , mginfo.xml & mgmirror.xml

·       Increase the <argument>-timeout</argument> parameter from 120 to 240 (the value is expressed in seconds)

·       Delete the old Deploy and work folder from Magic “XPI Installation Folder”\Runtime\Gigaspaces.
