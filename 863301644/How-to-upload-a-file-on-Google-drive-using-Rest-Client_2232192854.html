Magic Global Support : How to upload a file on Google drive using Rest Client

Created by Amjad Madre on 31,May, 2023

Product Line:

Integration Platform


Objective:

How to upload a file on Google drive using Rest Client.

 

Solution:

On this page, you will find the attachment of a sample example of the rest client in which we can upload an image to google drive.
Please go through the example.

In the google drive resource, when you click the 'Access token' button, you will need to select your email account.
Once you select your email account you will get a warning 'Google hasn’t verified this app'

Click on the Advanced button and proceed to Go to API project(unsafe).


After that click on the 'Allow' button so that the API project could access your email account.

In case that the ‘Allow' button which allows the API project to access the Google Account is disabled,

you will need to make the following changes to bypass this issue.

 

-Open the Registry Editor and go to the registry (regedit) and go to

 Computer\HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_BROWSER_EMULATION

 add a DWORD 32 bits, enter: "MgxpiStudio.exe" and the value 11000 as a decimal value.

 

 

 

 

 

Restart the magic xpi studio, the button in the Rest Client resource should be visible.

This suggestion works because the Internet Explorer version is changed to 11 and we can bypass the disabled 'Allow' button issue.


After that, the access token will be generated successfully.

 

 

 

Following this, run the project and you will see the image uploaded on google drive.
