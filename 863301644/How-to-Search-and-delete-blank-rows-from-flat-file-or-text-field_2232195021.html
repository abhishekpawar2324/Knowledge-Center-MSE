If we want to delete a blank row form any text file for Ex.-

Here we can see there is a blank row between “CC” and “EE”.

In that case we can achieve this using Flat file mapping in Data mapper using specific functions.

Here we took a flat and mapped it with another flat file.

 

After mapping the flat files we tried to achieve the scenario(Search and delete blank rows) by defining the function “IF (Len (Trim (Src.S3/Record/bb))=0,'FALSE'LOG,'TRUE'LOG)” This way.

 

We can see from the above screenshot we have used two mappings of flat files because we have tried with another function in the same way.

The function- Trim (Src.S5/Record/bb )<> ''

 

We can see from above screenshot, from context view if we Zoom the F.Blob2 or F.Blob3 , we can see that the blank row has been deleted.
