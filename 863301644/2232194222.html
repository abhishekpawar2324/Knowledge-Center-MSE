Magic Global Support : How to configure Progress DB (Open Edge) with XPI

Created by Amjad Madre on 31,May, 2023

You can download ProgressDB (OpenEdge) from the below link:

https://www.progress.com/

Support & Services >> click on Download Center

Browse by product >> click on OpenEdge

Then click on Download an evaluation product and it will ask you for login (create a new account on Progress DB)

 

Then click on Progress® OpenEdge®

 

Then click on Progress® OpenEdge® 12.2

Progress will provide you with 60 days trial license for different segments of OpenEdge (Take note for the license on notepad as we need those details while installing the OpenEdge

Then click on PROGRESS_OE_12.2_WIN_64_EVAL.zip

While installing it will ask you for License details, you can add multiple OpenEdge Segments licenses one by one.

OpenEdge supports JDK 11.0.4 and higher, so assign JDK 11 path for Java Home Directory

Once the installation is done then in the start menu click on Data Administration

To create a new database

Provide the database name and select a copy of the Sports2020 database and click OK.

Then need to add the user

Then in the start menu click on Database Administration Console

On the console login screen, the Default Username & Password is (“admin”)

Once you logged in it will ask you to change the password

Then you need to create a database in Progress DB

Under Resources click on Database

Then you need to update the below details to create a new Database and click on submit

e.g.

Admin Server: localhost

Database display name: Database-1

Database path and filename: add the path of the database created earlier through data administration

Database port: 2226

After creating the database in Progress DB need to add permissions

SQL permissions on an OpenEdge authentication gateway (OEAG) enabled database

You can refer below link:

https://community.progress.com/s/article/sql-permissions-on-an-openedge-authentication-gateway-oeag-enabled-database

Log in as default SQL DBA and OEAG authenticated user "sysprogress":

From start, the menu opens the proenv command line to add permissions

Then run the below commands:

Ø  proenv>sqlexp DB2(databasename) -S  2227(port)-user sysprogress -password password

Ø  select * from sysprogress.sysdbauth;

Ø  SQLExplorer>create user 'sqluser1','sqluser1';

Ø  SQLExplorer>commit;

Ø  SQLExplorer>grant dba to sqluser1;

Ø  SQLExplorer>commit;

Ø  SQLExplorer>SELECT * FROM sysprogress.sysdbauth;

 

Then you can try the connection with Progress DB using DBeaver

New connection setting update below details:

e.g.

Ø  Host: localhost

Ø  Post: 2225

Ø  Database/Schema: (Your database name)

Ø  Username and Password then click on Edit Driver Setting and openedge.jar and click ok.

Once the openedge.jar file is added then click on Test Connection

You have successfully connected to Progress DB OpenEdge from DBeaver.

Now we can use those details from DBeaver in the XPI resource to validate

Note: It’s working on XPI 4.13.3 with an Isolated fix provided on MXPI-24569 (Progress 2022-05-31.zip)

e.g

JDBC URL: jdbc:datadirect:openedge://localhost:2222;databaseName=fathom

Username: Your Progress DB username

Password: Your Progress DB password

Then click on validate
