Magic Global Support : Use of Multiple Statements in Single Datamapper Step

Created by Amjad Madre on 31,May, 2023

Customer would like to Execute three individual Statements in a single mapper step.

To Execute below are the following ways:

==Way 1

CREATE PROCEDURE dbo.DecryptContacts
    @skey NVARCHAR(100)
AS
BEGIN
    DECLARE @sql NVARCHAR(MAX);

    SET @sql = 'OPEN SYMMETRIC KEY ' + QUOTENAME(@skey) + ' DECRYPTION BY CERTIFICATE MagicDBBusinessAlfaCertif'
    SET @sql = @sql + ' SELECT ID, First_Name, CONVERT(VARCHAR(100), DECRYPTBYKEY(Encrypted_Last_Name)) AS Last_Name, Date_Created FROM Contacts1;'
    SET @sql = @sql + ' CLOSE SYMMETRIC KEY ' + QUOTENAME(@skey) + ';'

    EXEC sp_executesql @sql;
END

-- drop procedure DecryptContacts
--To execute--
EXEC dbo.DecryptContacts @skey = 'Sym_Key_Conns';
Way 2
==

CREATE PROCEDURE RunQuery
    @query NVARCHAR(MAX)
AS
BEGIN
    SET NOCOUNT ON;

    EXEC sp_executesql @query;
END
===

EXEC RunQuery 'OPEN SYMMETRIC KEY Sym_Key_Conns DECRYPTION BY CERTIFICATE MagicDBBusinessAlfaCertif;
SELECT ID, First_Name, CONVERT(VARCHAR(100), DECRYPTBYKEY(Encrypted_Last_Name)) AS Last_Name, Date_Created FROM Contacts1;
CLOSE SYMMETRIC KEY Sym_Key_Conns;';
