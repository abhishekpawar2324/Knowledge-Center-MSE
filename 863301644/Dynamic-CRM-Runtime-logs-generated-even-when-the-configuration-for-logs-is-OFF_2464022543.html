Magic Global Support : Dynamic CRM Runtime logs generated even when the configuration for logs is OFF

Created by Shweta Salunkhe on 28,Feb, 2024

Description:

In the Runtime/logs folder, the Dynamic CRM runtime logs (DynamicsCRM_runtime_14404.log) are generated even when the configuration for the logs is set to 'OFF'

Also, tried setting the OFF level in the 'Runtime/config/Log4net.config' file still it generates the logs.

Solution:

If customer don't want log file then we can remove one entry from Log4net.config' file, you can consider this work around, that's why reject this bug.

location-”C:\Magic xpi 4.14\Runtime\Config\Log4net.config”
