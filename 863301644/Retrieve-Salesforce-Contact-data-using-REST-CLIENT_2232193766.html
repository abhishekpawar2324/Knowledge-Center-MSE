Magic Global Support : Retrieve Salesforce Contact data using REST CLIENT

Created by Amjad Madre on 31,May, 2023

Create a Connected app in salesforce for Client ID and Client Secret:

Log in to Salesforce as an administrator.

Note: If you don’t have account - Sign up: https://developer.salesforce.com/signup

In the drop-down list of the account (in the upper-right corner), select Setup.

In the left-hand pane, go to Quick search and type Apps -> App manager.

In the App manager pane, click the New Connected Apps button.

On the New Connected App page, fill the following required fields under Basic Information:

Connected App Name. For example, Test App for Integration.

API name. For example, Test App for Integration.

Enter Contact Email.

Go to API (Enable OAuth Settings) and select Enable OAuth Settings checkbox.

In the Callback URL field, enter Ex.  https://localhost:8081/callback

In the Selected OAuth Scopes field, select Access and manage your data (API), and then click Add.

 

Click the Save button to save the new Connected App.

In the Connected Apps list, find the App that you just created, Click on View button to open details of the connected app.

Go to API (Enable OAuth Settings), and note down the Consumer Key and Consumer Secret, which will be used for the configuration of Credential in Test App for Integration.

 

Copy both secret key and consumer key

REST Client Resource Configuration:


-Open xpi settings(Ctrl+E) and add a Resource of REST_Client
-Fill details as below(Please refer attached sample project for better understanding)
1.Server URL:https://magicsoftware-b-dev-ed.my.salesforce.com
2.Security : select "OAuth2"
3.Authorizationn URL: https://login.salesforce.com/services/oauth2/authorize
4.Access Token URL: https://login.salesforce.com/services/oauth2/token
Ref for Endpoint URL Link

5.Callback URL: https://localhost:8081/callback
6.Client ID : (Consumer Key copied from connected app) Ex.3MVG9pRzvMkjMb6k.TAV6JtYbi.0YJo7OUmPjcA0fzDjjUIIcYp3N.Y4PNNU5JbBY.yDPmvbx_QqljYsAqKg
7.Client Secret: (Consumer Secret copied from connected app)
Ex.A8C2230B96B276CD04221F83B5CADB730990E7613D54EB9F0C8B378B13E8AE7
(Note: Client ID and Client Secret both details you will get in the SF connected apps settings)

Once you filled above details then click AccessToken and will open the SF login window

enter SF username and password, after login to SF account you will get the message Access token was generated successfully.

  • Then click on Paths and add new path and paste "/services/data/v43.0/sobjects/Contact"(to retrieve the contact details from SF) URL then click OK


-Then click Apply and OK


-Drag and drop the REST Client connector on flow and from the REST_CLIENT connector properties select Resource Name (Which we created in Resource) Ex. REST_CLIENT_1


-To configuration the connector right on REST Client connector and select configuration
-In Operation pane select Path from drop down list (path which we created in recourse)
-Select Operation as GET
-Security set to Yes

  • Then click OK

  • After that REST Client mapper will opened but no need to make any changes in it because we are just retrieving data without any filter then just save and close it.

 

  • Execute program

  • You will find contact records in C.UserBlob
