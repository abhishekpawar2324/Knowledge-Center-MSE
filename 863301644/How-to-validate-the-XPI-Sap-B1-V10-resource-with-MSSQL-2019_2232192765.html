Magic Global Support : How to validate the XPI Sap B1 V10 resource with MSSQL 2019

Created by Amjad Madre on 31,May, 2023

Magic XPI now supports SAP B1 9.3 with the MSSQL 2016 database.

 

Validate the resource of SAP B1 V10, need to do following changes,

·        Modify lines in resource_types.en.xml (%XPI_Installation%\Runtime\)

from

<ItemList>1,4,6,7,8,10,9</ItemList>

<DisplayList>MSSQL,MSSQL 2005,MSSQL 2008,MSSQL 2012,MSSQL 2014,MSSQL 2016,HANA DB</DisplayList>

to

<ItemList>1,4,6,7,8,10,9,15</ItemList>

<DisplayList>MSSQL,MSSQL 2005,MSSQL 2008,MSSQL 2012,MSSQL 2014,MSSQL 2016,HANA DB,MSSQL 2019</DisplayList>

 

·        Make the Registry Entry for SapbobsCOM.dll.

Note: The expected file path is C:\\Program Files (x86)\\SAP\\SAP Business One DI API\\DI API 100\\SAPbobsCOM100.dll (assuming that the sap installation is at the given path)

 

The registry contains,

[HKEY_CLASSES_ROOT\WOW6432Node\CLSID\{632F4591-AA62-4219-8FB6-22BCF5F60100}\InprocServer32]

@="C:\\Program Files (x86)\\SAP\\SAP Business One DI API\\DI API 100\\SAPbobsCOM100.dll"

"ThreadingModel"="Apartment"

 

Reference of XPI supports SAP B1 9.3: http://ftp.magicsoftware.com/ver/docs/Downloads/Magicxpi/4.7.9/Windows/ReleaseNotes4.7.9.pdf
