Magic Global Support : Saving .xlsx as .csv with New Excel Connector in XPI 4.14.1

Created by Abhishek Pawar on 25,Jul, 2025

In XPI version 4.14, users were unable to save an .xlsx file as a .csv file using the New Excel Connector. This issue has been resolved in XPI version 4.14.1.

Issue Description

In XPI 4.14, the 'Save Workbook' action in the New Excel Connector did not allow saving .xlsx files as .csv. Attempts to save would either fail or result in the file remaining in .xlsx format.

Resolution

The issue has been resolved in XPI 4.14.1. Users can now use the 'Save Workbook' action to save the file in .csv format by specifying the desired file path with a .csv extension.
