Magic Global Support : How to extract data from multiple Excel cells using the Range method.

Created by Amjad Madre on 31,May, 2023

Problem: -

The Customer wants to retrieve the data of a specified range of cells at once and set it to a variable.

e.g. – (A2 to D4)

Solution: -

This can be achieved by using the Range GetList method,

GetList: Gets the worksheet content into a memory table, which can be used with the List to XML method.

 

List to XML will save the XML result in a blob variable in XML format.

Further, you can refer attached sample project for a better understanding.

·         Download the project.

·         Try opening the zip file properties and click 'Unblock' and unzip.

·         Import the unzipped project and run it.
