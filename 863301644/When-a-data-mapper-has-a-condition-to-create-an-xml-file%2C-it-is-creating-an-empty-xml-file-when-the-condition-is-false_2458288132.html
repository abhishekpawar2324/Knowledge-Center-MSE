Magic Global Support : When a data mapper has a condition to create an xml file, it is creating an empty xml file when the condition is false

Created by Vinayak Dane on 23,Feb, 2024

Customer Issue: There is a problem that when a data mapper has a condition to create an xml file, it creates an empty xml file when the condition becomes false.

 

Affected version:4.13.5

 

On further investigation, we understand this is the expected behavior,

There is no bug here but how the architecture of Destination XML is implemented.

·        The XML on the destination will always be created - the condition is checked after the XML file is initialized.

·        The condition is on the Row level meaning that the content of the XML is conditioned and not the creation.

·        To implement the desired behavior that the XML will be created conditionally you MUST use CallFlow - Condition the call flow and so the XML created in the sub-flow will not be executed.
