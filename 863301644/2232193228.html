Magic Global Support : Datamapper: Single Quote in Where Condition

Created by Amjad Madre on 31,May, 2023

Scenario: The received string contains Single Quote (') which can be anywhere in the string.
When use the variable in the string (it throws the error due to the missing one Single Quote)

** As a workaround, which can help and can be worked dynamically (any type of string which contains single quote any where in the string).

Using RepStr () , it searches for the (') in the string and replaced with the (Two Single Quote).
So in where condition this can be used , like as below :
SELECT [ID1].ID,[ID1].Name FROM dbo.[ID1] WHERE dbo.[ID1].Name='De''Name'

Attaching the sample with the Script with Data.
In the logic - there is a HTTP Trigger where the string can be passed - for where condition via ENV Variables.
Before that- using Flow Data - so the ENV Variable can be updated.
