Magic Global Support : Data Converter: How to use the pipe character (|) as a delimiter for the conversion table.

Created by Amjad Madre on 31,May, 2023

Objective:

The customer is using the pipe character (|) as a delimiter for the conversion table and observed that it does not work properly.
As per our help, the customer also tried using \\| but it does not work.

Solution:

Data conversion using the pipe character (|) as a delimiter for the conversion table will work when we use “\|” as a delimiter in the conversion table but please note that the file itself should only contain “|”.

This was a documentation issue,
As in the help 'Home > Reference Guide > Utilities > Data Mapper Utility > Data Converter > Data Converter Repository'
it is mentioned that If you use the pipe character (|) as a delimiter, you need to prefix it with two forward slashes: \\|.
This will be corrected in future versions of XPI.

Please see the attached working sample project using the pipe character (|) as a delimiter for the conversion table.
