Magic Global Support : How to Modify the Endpoint Alias for Magic xpi Project

Created by Abhishek Pawar on 07,May, 2025

Version: Magic xpi 4.14.1

Problem Description

Customer is trying to modify the endpoint alias for their Magic xpi projects.

Example endpoint format:

http://<host>/<Magic xpi>/MgWebRequester.dll?appname=IFS<projectname>&prgname=HTTP&arguments=-A<ServiceName>#<TriggerName>&<Parameter1Name>=<Parameter1Value>

Current Configuration:

  • Current Webserver alias in IIS: Magicxpi4.14.1

  • Desired new alias: magic

Customer followed these steps:

  1. Edited the alias in Project settings > Services

  2. Restarted the Agent

  3. Restarted the Project

  4. Restarted IIS

However, the endpoint still used the old alias and didn’t reflect the change.

Root Cause

The alias configured in the project settings is not sufficient by itself. The endpoint alias is determined by the virtual directory (or application) configuration in IIS and must match the internal environment alias defined in Magic xpi.

 

Resolution Steps

To change the alias to magic, follow these steps:

  1. Create a new alias (Virtual Directory or Application) named magic under IIS → Default Website.

    • Note: This alias should point to the Runtime/scripts folder of your Magic xpi installation (the folder where MgWebRequester.dll resides).

  2. In the Magic xpi Studio, go to:

Project → Settings → General Environment → Internal Environment Variables

  1. Change the value of the variable Alias to match the alias set in IIS, i.e., magic.

  2. Apply the changes and restart the following components:

    • Restart IIS

    • Restart the Agent

    • Restart the Project

Result

You should now be able to access the endpoint using:

http://<host>/magic/MgWebRequester.dll?appname=IFS<projectname>&...

The endpoint will now correctly recognize the new alias.
