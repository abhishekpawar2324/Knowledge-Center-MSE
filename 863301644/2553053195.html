Magic Global Support : SharePoint: Download files from the Root folder only and not from the sub-folder.

Created by Abhishek Pawar on 17,Apr, 2024

Description:

Files from the sub-folder are downloaded even when we do not select the include sub-folder while configuring the step.
The customer only wants to download files from the Root folder and not the sub-folder.

 Resolution:

This is the product behavior and solution to Download only files in the Root folder is as follows:

We must define '.' in the Folder field while configuring the SharePoint step.

(please refer to the attached screenshot).

The above solution is documented from XPI version 4.13.6 to help

Refer Help: Home > Component Series > SharePoint > SharePoint - Configuration > SharePoint – XML

This solution also works for XPI lower versions. (XPI 4.13.5 and 4.13.4 and 4.13.3)
