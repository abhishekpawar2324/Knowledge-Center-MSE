Oracle Database Installation on Windows

Part 1: Oracle Database Server Installation

Step 1: Extract the downloaded Oracle Database ZIP

Select Extract All → Choose a simple folder like C:\OracleDB.

  • Path should not have spaces (avoid "Program Files").

 

Step 2: Launch Oracle Installer
Oracle 12c Release 2\server\database

·       Go into the extracted folder.

·       Run setup.exe as Administrator (right-click → Run as Administrator).

 

Step 3: Configuration Option

  • Choose "Set Up Software Only" or "Create and Configure a Single Instance Database".

Step 4: System Class

  • Select:

    • Desktop Class (for simple laptop/desktop installation)

Step 5: Oracle Home User

  • Choose:

    • Use Windows Built-in Account (easy for testing)

Step 6: Installation Location

  • Example:

    • Oracle Base: C:\app\STadke

    • Software Location: C:\app\STadke\product\19.0.0\dbhome_1

Step 7: Database Creation (if selected earlier)

  • Global Database Name: Example → ORCL

  • SID: It will default to ORCL.

Step 9: Summary and Install

  • Review all configurations.

  • Click Install to start installation.

  • It will take 10-15 minutes.

Step 10: Database Configuration Assistant (DBCA)

  • At the end, you'll get a Database URL like:

    • https://localhost:5500/em (Enterprise Manager link)

Part 2: Oracle Client Installation

Step 1: Extract the downloaded Oracle Client ZIP

Select Extract All → Choose a simple folder like C:\OracleClient.

  • Path should not have spaces (avoid "Program Files").

 

Step 2: Launch Oracle Client Installer

C:\OracleClient \Oracle 12c Release 2\client\client32

  • Go into extracted folder.

  • Run setup.exe as Administrator.

 

Step 3: Installation Type

Choose:

  • Custom

Step 4: Specify Oracle Home User

·       Select User Windows Build-in Account

Step 5: Oracle Home Directory

  • Choose:

    • Oracle Base: C:\app\client\STadke

    • Software Location: C:\app\client\STadke\product\12.2.0\client_1

Step 6: Select Product Components

·       SQL *Plus

·       Oracle Call Interface (OCI)

·       Oracle Net

·       Oracle ODBC Driver

·       Oracle SQL Developer

Step 5: Perform Prerequisite Checks

  • Installer will check requirements.

  • Proceed if all is good.

Step 6: Install

  • Review and click Install.

Step 7: Post Installation (Network Configuration)

·       Copy the following files from the location C:\app\STadke\product\12.2.0\dbhome_1\network\admin

  • sqlnet.ora

  • tnsnames.ora

·       Please ensure that you place these files in the following directory: C:\app\client\STadke\product\12.2.0\client_1\network\admin

Step 8: Set Environment Variables

Set these in Windows System Properties > Environment Variables:

·       TNS_ADMIN → C:\app\STadke\product\12.2.0\dbhome_1\network\admin
