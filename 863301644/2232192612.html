Magic Global Support : Issue with fsutil 8dot3name set c: 0 command

Created by Amjad Madre on 31,May, 2023

Problem:

Magic xpi requires 8dot3name support when it is installed in a location that contains spaces.

When executed command fsutil 8dot3name set <required installation drive> 0

For example: fsutil 8dot3name set c: 0

Get an error as ‘Short name settings may not be changed on this volume due to the global registry setting. ’

Solution:

Open 'Registry Editor' and locate the following registry key:

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\FileSystem

 

  1. Select the 'NtfsDisable8dot3NameCreation' entry.

  2. On the Edit menu, Modify click DWORD. Type a value of 2 in the Data field.

  3. Click OK and then exit Registry Editor.

  4. Restart your computer

 

Now if you try fsutil 8dot3name set c: 0

It will get successfully enabled 8dot3name generation on c:
