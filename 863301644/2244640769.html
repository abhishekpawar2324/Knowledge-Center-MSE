Magic Global Support : IF_4.13.6 - Error 9999: Get operation failed...' error appears when the Parameterized Rest Client path is used as resource

Created by Prachi Palande on 14,Jun, 2023

Isolated fix applicable version – XPI 4.13.6

Fixed version: XPI 4.14

Problem Description:

Error on GET operation when the Parameterized Rest Client path is used as a resource.

Error: 9999
"GET operation failed. java.lang.IllegalArgumentException: Illegal character in path at index 55: http://10.9.3.56:7048/BC/api/aby/abyEDI/v1.0/companies({COMPANY})/abyEDIOutboundEntries."

With an endpoint without Parameterized path gets the expected response.

Instruction to use the fix:

·  The fix is in zip folder name mgxpi-restclient.zip

·  Please make sure the XPI services and Studio should be stopped/closed before applying this isolated fix.

·  Copy mgxpi-restclient.jar file in "\Runtime\addon_connectors\RestClient\\runtime\java
lib" folder.

·   Take backup of old file(mgxpi-restclient.jar) outside Magic XPI Installation.

·   DO NOT keep the original/existing jar file in xpi installation folder and create a back up outside xpi installation.
