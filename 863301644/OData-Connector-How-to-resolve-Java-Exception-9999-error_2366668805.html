Magic Global Support : OData Connector-How to resolve Java Exception-9999 error

Created by Shweta Salunkhe on 26,Dec, 2023

Problem:

The customer is getting the 'Error message: "Java Exception", error code 9999' in the Magic Monitor

for the OData connector in XPI.

There is no error observed in the debug-level logs.

Solution:

In the Session below are observations:

We can see that the filter with an extended entity throws the error in the monitor as a Java execution but in the debug logs
We did not see any errors.

In the stderr log file, we can see the Java heap space out-of-memory error.
We suspected that this might be the issue with the Java execution error.

So, we changed the JVM_ARGS memory to 4GB, and it works as expected.

This resolved the issue.
