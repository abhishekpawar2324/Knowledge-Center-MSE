Magic Global Support : How to define values like list in Project Environment User variables in XPI.

Created by Abhishek Pawar on 26,Nov, 2024

Description:

The customer trying to get some values from my User Environment Variables (Project Environment).
For this, they created a variable called "Email Recipient" which contains 2 mail addresses.
Later they want to use this variable to send some mails.

The value is for example: "Mail1@test.com, Mail2@test.com".
The problem: they only get "Mail1@test.com". Everything after the comma is missing.

CASE NUMBER: 00103764

Solution:

User Environment Variable from the 'Project Environment' itself has limitations so we can observe differences in behaviour. We have a workaround for this.
Workaround 1:

If we use an asterisk (*) at the start of the email list in the Project Environment User variable, followed by values separated by commas, it will work correctly and send emails to all specified addresses.

For example *Mail1@test.com, Mail2@test.com


 

=====================================================================

Workaround 2:

Whereas if we use the User Environment Variable from the 'Project Environment' tab then name values inside single quotes separated by a comma works fine.

 

For Example:  ‘aaa,bbb, ccc,ddd’
