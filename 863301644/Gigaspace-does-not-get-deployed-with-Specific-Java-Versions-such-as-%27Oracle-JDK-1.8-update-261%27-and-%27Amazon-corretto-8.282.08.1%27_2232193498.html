Magic Global Support : Gigaspace does not get deployed with Specific Java Versions such as 'Oracle JDK 1.8 update 261' and 'Amazon-corretto-8.282.08.1'

Created by Amjad Madre on 31,May, 2023

Problem Description:

Gigaspace does not get deployed with Specific Java Versions such as 'Oracle Java version 1.8 update 261' and 'Amazon-corretto-8.282.08.1'

 

Shows below error when started Gigaspace manually using command prompt:

The problem happens in both English and Japanese version of xpi.

Solution:

This seems to be an issue due to incompatibility of Sigar library.

It can be resolved by renaming sigar folder as mentioned below:

 

Please follow the below steps:

  • Stop all xpi services.

  • Rename the sigar folder from '<Magic xpi installation>\Runtime\Gigaspaces\lib\optional\sigar' location.

  • Restart the xpi services and check that Gigaspace has deployed properly.
