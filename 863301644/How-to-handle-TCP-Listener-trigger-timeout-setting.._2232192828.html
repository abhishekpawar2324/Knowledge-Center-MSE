Magic Global Support : How to handle TCP Listener trigger timeout setting..

Created by Amjad Madre on 31,May, 2023

Platform Line: Magic XPI

 

Objective:

How to handle TCP Listener trigger timeout setting.

 

Problem:

If you experience this scenario where TCP Listener trigger getting a timeout. One of the scenarios where the default is zero so there is no timeout. However, it gets time out in 30 seconds.

 

Please refer to the below screenshot of mgreq.ini which shows the RequesterTimeoutSec setting.

Solution:

The solution needs to do the following.

In mgreq.ini the   RequesterTimeoutSec is default 30 seconds is the default.

For this issue, if we try this setting so after increasing the setting from requester timeout to 120 seconds (RequesterTimeoutSec = 120) in mgreq.ini from %installation%/Runtime.
This works correctly as expected with the TCP Listener trigger.

Below screenshot shows RequesterTimeoutSec=120 seconds.
