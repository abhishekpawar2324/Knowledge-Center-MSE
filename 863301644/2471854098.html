Magic Global Support : XPI 4.14: How to know project status using the command line

Created by Vaishnavi Marathe on 04,Mar, 2024

We had requirement from customer that he wanted to know the project status using command line in XPI 4.14.

After consulting with our Product Management, we got the following workaround:

We can check the project status using Redis - cli tool and executing the command  below:

 

"redis-cli -h <HOSTNAME> JSON.GET ProjectData:<ProjectName> ..projectState"

 

Please find the screenshot for reference:

Firstly we need to install the Redis cli tool:

To download the Redis cli tool refer the following link:
https://redis.io/docs/install/install-redis/install-redis-on-windows/

 

Once the redis cli tool is downloaded and installed on windows machine:

We need to install the redis cli tool on the Linux(Ubuntu) machine by below command:

sudo apt install redis-tools

(to install the Redis tools package on a Debian-based system using the Advanced Package Tool (APT). This package typically includes command-line utilities for working with Redis, such as redis-cli (the Redis command-line interface) and other tools for managing and interacting with a Redis server)

 

After installing the redis tool we need to start the redis server by below command or it will throw the below error:

-sudo service redis-server start

(To start the Redis server on a system that uses a service manager like systemd or init.d. This assumes that Redis is installed on your system and that the service is configured.)

 

Once the server is started you can check the server is reached or not by below command:

redis-cli ping

If the server is reachable and operation it will return “PONG”

 

Extra:

Powershell commands to be executed ->

ssh magicvm@172.26.4.102

(to initiate an SSH (Secure Shell) connection to a remote host with the IP address)

curl -fsSL https://packages.redis.io/gpg | sudo gpg --dearmor -o /usr/share/keyrings/redis-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/redis-archive-keyring.gpg] https://packages.redis.io/deb $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/redis.list

If you're running a very minimal distribution (such as a Docker container) you may need to install lsb-release, curl and gpg first:

sudo apt-get update

sudo apt-get install redis
