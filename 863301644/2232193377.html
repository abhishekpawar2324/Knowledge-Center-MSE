Magic Global Support : Problem: Error: StartServers validate - parameter startup-config-file missing

Created by Amjad Madre on 31,May, 2023

Solution:

We have found the following problem in the Magic XPI 4.12 release installation:

If the machine where the Magic XPI 4.12 is installed does not have the 'C:\Temp' folder, Magic XPI projects cannot run.

The symptom is the project is going to fail and be restarted in an endless cycle.

Adding the C:\Temp folder and restarting the GSA service resolves the problem,

the reason for the issue has been already identified and the problem is going to be fixed in 4.12.1.
