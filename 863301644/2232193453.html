Magic Global Support : REST Client containing special characters(,$....)

Created by Amjad Madre on 31,May, 2023

When path’s contain special character an new parameter was introduced in 4.13.1 that will encode these characters in a correct way:

[MAGIC_IBOLT]RestClientPathParamURlEncode=Y
