Magic Global Support : SAP ERP Studio logging for Trigger and Step

Created by Amjad Madre on 31,May, 2023

Generate the SAP ERP components studio logs using java code.

·         close the XPI Studio

·         In <XPI ROOT>\Studio\MgxpiStudio.exe.config add the next info that are highlighted by the font

--------

<configuration>

<configSections>
<section name="msbuildToolsets" type="Microsoft.Build.BuildEngine.ToolsetConfigurationSection, Microsoft.Build.Engine, Version=4.0.0.0, Culture=neutral, PublicKeyToken=b03f5f7f11d50a3a" />
<section name="JavaSettings" type="JNI.NET.Bridge.Jni.Net.Utils.JavaSettingsSectionHandler, JNI.NET.Bridge" />
</configSections>
<JavaSettings>
<options>
<add id="ibolt-home" value="-Dcom.magicsoftware.ibolt.home=C:/MAGICX~1.13/Runtime"></add>
<add id="logback" value="-Dlogback.configurationFile=C:/MAGICX~1.13/Runtime/Java/classes/logback.xml"></add>
</options>
</JavaSettings>

--------

Please correct XPI Studio Root path C:/MAGICX~1.13 in this file so that it matches your configuration. Note: This path should have the short Windows path form.

·         remove all old log files from <XPI Studio Root>\Runtime\logs\java

·         open the SAP ERP project and try to load metadata

·         The SAR ERP log files should appear in the <XPI Studio Root>\Runtime\logs\java
