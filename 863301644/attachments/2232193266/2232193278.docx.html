From the event log, it seems that the operating system isn’t able to spawn a new process, since it failed to create a handle (i.e Kernel level objects are not getting created).

The solution to increase the limit for kernel level limit is listed in #3 above.

e.g.

Registry key: HKEY_LOCAL_MACHINE \System\CurrentControlSet\Control\Session Manager\SubSystems

Registry Value: Windows

Registry value:

%SystemRoot%\system32\csrss.exe ObjectDirectory=\Windows SharedSection=1024,20480,768 Windows=On SubSystemType=Windows ServerDll=basesrv,1 ServerDll=winsrv:UserServerDllInitialization,3 ServerDll=sxssrv,4 ProfileControl=Off MaxRequestThreads=16

Change it to:

%SystemRoot%\system32\csrss.exe ObjectDirectory=\Windows SharedSection=1024,20480,1024 Windows=On SubSystemType=Windows ServerDll=basesrv,1 ServerDll=winsrv:UserServerDllInitialization,3 ServerDll=sxssrv,4 ProfileControl=Off MaxRequestThreads=16
