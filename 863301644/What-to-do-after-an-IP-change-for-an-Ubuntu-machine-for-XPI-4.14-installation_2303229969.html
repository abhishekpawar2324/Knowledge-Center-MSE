Magic Global Support : What to do after an IP change for an Ubuntu machine for XPI 4.14 installation

Created by Rohan Karekar on 03,Oct, 2023

Whenever the IP changes we need to update the config file. To update the config file need to follow the below steps.

 

Follow the below steps to redeploy IMM:

§  sudo apt-get update && sudo apt-get install -yqq daemonize dbus-user-session fontconfig

§  sudo daemonize /usr/bin/unshare --fork --pid --mount-proc /lib/systemd/systemd --system-unit=basic.target

§  exec sudo nsenter -t $(pidof systemd) -a su - $LOGNAME

§  Disable microk8s DNS using  “sudo microk8s disable dns”

§  Disable microk8s metallb using “sudo microk8s disable metallb”

§  Reenable DNS and metallb using “sudo microk8s enable dns” and “sudo microk8s enable metallb” respectively

§  After enabling metallb it prompts for IP range, specify it as <IP Address>-<IP Address>

§  Create a Config file using “microk8s config > config”

§  Copy the new config file to %UserProfile%/.kube folder
